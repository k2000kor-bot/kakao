# 프로젝트별 노트북 LLM 학습 및 질의응답 사용 가이드

## 요약
- **프로젝트를 만들 때** 입력한 이름·설명·태그·가이드라인이 백엔드에 저장되고, 노트북 LLM이 이 정보를 “학습”해 둡니다.
- **해당 프로젝트에서 대화할 때** 질문·요청에 대해 이 학습된 정보를 반영한 답변이 나옵니다.

## 소스 그라운딩 (Google NotebookLM 스타일)
- 답변은 **업로드·학습된 프로젝트 정보(소스)** 를 우선 근거로 합니다.
- 학습된 가이드라인·설명과 맞지 않는 내용은 포함하지 않도록 유도됩니다.
- 학습된 정보에 없는 내용을 보충할 때는 **(추정)**, **(학습된 소스 밖의 보충 정보)** 등으로 구분해 표시합니다.
- 어떤 응답 경로를 사용하든(고급 AI 엔진 또는 노트북 LLM), 프로젝트 학습 정보가 있으면 그 맥락을 반영한 답변이 생성됩니다.

## 사용 방법

### 1. 프로젝트 생성 (학습 정보 입력)
- 대화 화면에서 **새 프로젝트**를 만듭니다.
- **프로젝트 생성 모달**에서 다음을 입력할 수 있습니다.
  - **이름** (필수)
  - **설명**
  - **우선순위**
  - **태그**
  - **가이드라인** (여러 줄): 이 프로젝트에서 AI가 따르면 좋을 규칙, 톤, 제약 등을 적습니다.
- **생성**을 누르면 백엔드에 저장되고, 위 내용이 노트북 LLM용 컨텍스트로 한 번에 저장·학습됩니다.

### 2. 프로젝트에서 질문/요청하기
- 생성한 프로젝트를 **선택한 상태에서** 대화창에 질문하거나 요청을 입력합니다.
- 백엔드가 해당 프로젝트의 저장된 정보를 불러와, 그 컨텍스트를 반영한 답변을 생성합니다.
- 따라서 프로젝트 설명·가이드라인에 맞는 톤과 내용으로 답변할 수 있습니다.

### 3. 프로젝트 설정 편집
- 대화 화면에서 **「프로젝트 설정」** 버튼을 누르면, 해당 프로젝트의 이름·설명·태그·가이드라인을 수정할 수 있습니다. 저장하면 노트북 컨텍스트도 함께 갱신됩니다.
- 웰컴 화면(대화 없을 때)에서도 프로젝트가 선택되어 있으면 **「프로젝트 설정」** 으로 같은 편집이 가능합니다.

### 4. 스튜디오 (보고서·퀴즈·요약 등 생성)
- 프로젝트를 선택한 대화 화면에서 **「스튜디오」** 버튼을 누르면, 학습된 소스만 사용해 다음 형식을 생성할 수 있습니다.
  - **보고서**: 제목·요약·본문·결론 구조의 보고서
  - **학습 가이드**: 핵심 개념·정리·확인 질문
  - **퀴즈**: 5문항 (문제·정답·해설)
  - **요약**: 핵심 요약
  - **플래시카드**: Q/A 5쌍
- 생성된 내용은 모달로 표시되며, AI가 만든 내용이므로 필요 시 확인·수정해 사용하세요.

### 5. 소스 추가·관리 (다중 소스)
- 프로젝트에는 기본적으로 **프로젝트 개요** 1개 소스가 있습니다. 대화 화면에서 **「소스 추가」** 버튼을 누르면 **소스 추가 · 관리** 모달이 열립니다.
- **현재 소스** 목록에서 추가한 소스는 **삭제** 버튼으로 제거할 수 있습니다. 프로젝트 개요는 삭제할 수 없습니다.
- **새 소스 제목**과 **본문**을 입력한 뒤 **추가**를 누르면 목록에 반영되고, 대화·스튜디오에서 바로 사용됩니다. 소스 N개도 갱신됩니다.
- API: 추가 `POST /api/projects/{id}/notebook-sources` (body: `{ "title", "content", "type" }`), 삭제 `DELETE /api/projects/{id}/notebook-sources/{source_id}`.

### 6. 참고
- 프로젝트를 **수정**해 이름·설명·태그·가이드라인을 바꾸면, 저장된 노트북 컨텍스트도 함께 갱신됩니다.
- 프로젝트를 **삭제**하면 해당 프로젝트의 노트북 컨텍스트 파일도 함께 삭제됩니다.
- 학습 데이터는 프로젝트별로 `project_data/project_knowledge/{project_id}.json` 형태로 저장됩니다.
- 사이드바와 대화 입력 영역에는 **「소스 N개」** 로 학습 소스 개수가 표시됩니다 (Google NotebookLM 스타일).

## 체계적으로 학습시키는 방법
- **노트북 = 프로젝트 하나**로 두고, 주제별로 소스를 넣은 뒤 **같은 노트북에서만** 대화·스튜디오를 사용하면, 나중에 “이 노트북에 어떤 소스가 있고 어떤 답이 나왔는지”를 일관되게 관리·개선할 수 있습니다.
- 권장 순서: (1) 노트북(프로젝트) 생성 → (2) 지침(가이드라인) 입력 → (3) 소스 추가(파일·URL·텍스트) → (4) 해당 노트북에서 대화·스튜디오 사용 → (5) 답변이 어긋나면 지침 보강 또는 소스 추가/삭제.

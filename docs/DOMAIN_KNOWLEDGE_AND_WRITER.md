# 도메인 전문 지식 및 작가 기능

도시정비·재건축·재개발·부동산·조합 관련 **전문 지식**과 **조합원 정보·여론을 위한 작가 기능** 정리.

---

## 1. 도메인 전문 지식 (DeepSeek 등 LLM 연동)

### 1.1 대상 분야

다음 분야의 지식을 시스템이 보유하고, **딥시크 LLM** 호출 시 요청/프로젝트 맥락에 따라 자동으로 프롬프트에 주입합니다.

| 분야 | 내용 |
|------|------|
| **도시정비법** | 도시 및 주거환경정비법, 정비구역·조합설립·관리처분·시공사 선정·입찰·분양·이주 등 |
| **국토부** | 국토교통부 정책·지침·고시, 계약업무처리기준, 시공자 선정, 정비사업정보시스템 |
| **계약체결** | 조합·시공사 계약, 계약서 일반조항·특약·해지·손해배상, 부동산 매매·임대차 |
| **부동산정책** | 분양가상한제, 재건축·재개발 규제·완화, 임대차3법, 시기별 대책 |
| **부동산시장** | 주택가격·전세·LTV·DTI·담보대출·리츠 등 시장 맥락 |
| **변호사** | 조합·시공사 자문, 입찰·계약 분쟁, 명의신탁·의결권·총회 결의·분담금 분쟁 |
| **변리사** | 지식재산권·특허, 기술·설계 관련 분쟁·권리 검토 |
| **법무사** | 등기·신청서·민사·집행·경매·전세권·저당권·소유권이전 |
| **세무사** | 양도소득세·취득세·1세대 1주택 비과세·이주비·분담금·청산금 세무 |
| **부동산중개사** | 중개·설명의무·중개대상물 확인·손해배상 판례 |
| **감정평가사** | 분담금·청산금 산정, 시가산정, 정비사업전문평가사 |
| **재건축 판례** | 조합원 의결권·총회 결의·분담금·입찰 무효·특혜·정관·반대편입 등 |
| **재개발 판례** | 권리관계·이주·보상·전세권 우선변제·임대차 보증금 등 |
| **조합업무처리** | 조합장·이사회·감사·사무국·총회·대의원회·의사록·회의록·정보몽땅·e-조합 |

### 1.2 적용 경로

- **파일**: `backend/domain_knowledge_urban.json` — 위 분야별 요지·절차·용어가 `sections`에 정의되어 있음.
- **로드**: `backend/llm_service.py` — `_load_domain_knowledge_urban()`로 JSON 로드, `keywords_trigger`로 트리거 판단.
- **주입**: `_enhance_with_knowledge()` — 사용자 메시지 또는 `projectKnowledge`에 트리거 키워드(도시정비, 재건축, 조합, 국토부, 계약, 변호사, 세무사 등)가 포함되면, **요청 메시지 앞에** `[도메인 전문 지식]` 블록을 붙여 DeepSeek(설치형/API) 및 기타 provider에 전달. 답변 시 위 지식을 근거로 활용하도록 유도.

### 1.3 트리거 키워드 (일부)

도시정비, 재건축, 재개발, 조합, 국토부, 계약, 부동산, 변호사, 세무사, 감정평가, 판례, 법무사, 변리사, 중개사, 정비사업, 분담금, 시공사, 정관, 총회, 이사회, 관리처분, 분양, 입찰, 정비구역, 조합설립, 이주, 청산금, 건축심의, 양도소득세, 취득세, 감정평가사 등.  
전체 목록은 `domain_knowledge_urban.json`의 `keywords_trigger` 참고.

### 1.4 학습된 전문지식 (프로젝트 소스)

**프로젝트에 추가한 소스(파일·URL·텍스트·지침)**가 곧 **학습된 전문지식**으로 사용됩니다.

- **저장**: 프로젝트별 노트북 소스는 `project_data/project_knowledge`에 저장되며, 대화/노트북 LLM 요청 시 `load_project_notebook_context_filtered`로 로드됩니다.
- **반영 경로**:  
  - 백엔드 `generate_chat_response`에서 `context["projectKnowledge"]`에 넣고,  
  - `llm_service._enhance_with_knowledge()`에서 **[프로젝트 컨텍스트·지침·참고 소스]** 블록으로 최대 8000자까지 프롬프트에 포함합니다.  
  - 파이프라인 수집 자료에는 **프로젝트_지식**으로 최대 4000자·요약 2000자까지 포함되며, **[수집 자료]**로 LLM에 전달됩니다(최대 2500자).
- **도메인·전문가 지시**: 노트북 LLM에서 **도메인(지식)**을 선택하면 `domain_instruction`·`expert_instruction`이 context에 포함되고, 백엔드 4단계에서 `_style_and_tone_instruction`에 합쳐져 **[스타일 지시]**로 전달됩니다.  
즉, **프로젝트 소스를 추가하면 해당 내용이 학습된 전문지식으로 대화·노트북 답변에 반영**됩니다.

## 2. 작가 기능 (조합원 정보 습득·감정·여론 통합)

조합원이 **제대로 된 정보를 습득**하고, **감정과 여론을 하나로 모아** 활용할 수 있도록 다음 기능을 갖춥니다.

### 2.1 기반 기능

- **44개 글쓰기 스타일** (문학·비평·평론·저널리즘·학술·창작·전문직·사회) + **어투/말투** + **연령대별 말투** — `writingStyleService`, `NotebookLLM` 연동.
- **노트북 LLM** — 프로젝트별 학습·정리·도메인 지식(도시정비·세무·법무·감정평가 등) 선택 후 답변 생성.
- **프로젝트 지침·소스** — 프로젝트 설정 지침·첨부 파일·노트북 소스가 대화/노트북 답변에 반영됨 (DeepSeek 연동 포함).

### 2.2 조합원 전용 프리셋 (도시정비/재건축/재개발 프로젝트)

프로젝트 태그에 **도시정비·재건축·재개발**이 포함된 경우, 대시보드·퀵 프롬프트에 아래 두 가지가 노출됩니다.

| 프리셋 | 용도 |
|--------|------|
| **조합원 정보 전달 글** | 조합원이 올바른 정보를 습득할 수 있도록, 현재 프로젝트·대화 맥락을 바탕으로 **정확하고 이해하기 쉬운 안내 글** 작성. 사실과 근거 구분, 오해 소지 항목은 확인 질문 형태로 정리. |
| **감정·여론 통합** | 대화·자료에 담긴 조합원·관계자의 **감정과 여론을 하나로 모아 요약**. 공통 관심사·우려, 대립 의견, 합의 가능 지점, 추가 수렴 필요 항목 순으로 정리. |

- **적용 위치**: `src/components/ChatGPTInterface.tsx` — `getDashboardQuickPrompts` 내 도시정비/재건축/재개발용 `deliverableTemplates`에 위 두 항목 추가.

### 2.3 추가 활용

- **실무 산출물**: 조합 보고서 초안, 수주 점검표, 주민 설명회 Q&A, 도메인 실무 점검 등 기존 템플릿과 함께 사용.
- **품질 검토**: 근거 출처 검증, 리스크 누락 점검으로 정보 전달 글·여론 요약의 신뢰도를 보완.

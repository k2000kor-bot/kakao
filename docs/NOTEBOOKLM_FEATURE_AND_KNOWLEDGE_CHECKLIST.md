# NotebookLM 스타일 기능·기본 지식 체크리스트

화면에 있는 기능이 모두 고려되어 구축되는지, 그리고 **재건축·재개발 관련 기본 지식**(도시정비법, 대법원 판례, 전문가 영역)이 갖춰져 있는지 정리한 체크리스트입니다.

> **구글 노트북 LLM과 동일한 서비스로 쓰기·체계적 학습**: [NOTEBOOKLM_SERVICE_AS_GOOGLE.md](./NOTEBOOKLM_SERVICE_AS_GOOGLE.md)

### 2.4 분야별 지식·글쓰기 스타일·딥러닝·노트북 LLM 보강 (2026-02)

| 항목 | 구현 | 비고 |

| **분야별 지식 디테일** | `DOMAIN_KNOWLEDGE_BASE`에 `keyPoints` 추가 (도시정비·세무·법무·감정평가·대법원판례·건축법·계약·회계). `buildIntelligentContext`에서 핵심 포인트 포함. | 답변 시 참고할 요지 명시 |

## 3. 요약

- **화면 기능**: 출처(소스 추가·목록·삭제), 대화(소스 N개·추천 질문·그라운딩), 스튜디오(보고서·퀴즈·마인드맵·슬라이드·데이터 표 등)는 **기본으로 반영**되어 있음. Deep Research·웹/Fast Research·분석·공유·설정은 로드맵 Phase 3~5 예정.

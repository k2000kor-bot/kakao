# 🤖 개포우성 재개발 프로젝트 AI 분석 시스템 사용자 가이드

## 🚀 시작하기

### 시스템 접속

- **웹 주소**: <http://localhost:3001>
- **시스템 상태**: 완전 가동 중 ✅
- **지원 브라우저**: Chrome, Firefox, Safari, Edge

### 첫 번째 사용

1. 브라우저에서 <http://localhost:3001> 접속
2. 사이드바에서 "개포우성7차" 프로젝트 선택
3. "개포우성 분석" 버튼 클릭
4. 분석 시스템 메인 화면으로 이동

## 📊 분석 모드 선택

### 1. 📊 전통적 분석 모드

**파일 기반 분석** - 업로드된 문서를 기반으로 한 구조화된 분석

#### 사용 방법

1. **파일 업로드**: PDF, Word, Excel, 이미지 등 다양한 파일 업로드
2. **분석 타입 선택**:
   - 종합 분석
   - 연구자 관점
   - 정책분석가 관점
   - 여론분석가 관점
   - 부동산 전문가 관점
   - 사회학적 관점
3. **분석 실행**: "종합 분석 시작" 또는 "빠른 분석" 버튼 클릭

### 2. 🤖 고도화된 AI 분석 모드

**ChatGPT 스타일 자연어 분석** - 자유로운 질문으로 깊이 있는 분석

#### 사용 방법

1. **자연어 질문 입력**: 텍스트 영역에 질문 입력
2. **AI 분석 실행**: "🤖 AI 분석 시작" 버튼 클릭
3. **결과 확인**: 구조화된 분석 결과 확인

## 📋 분석 결과 해석

### 🤖 고도화된 AI 분석 결과 구성

#### 1. 💬 직접 답변

- 사용자 질문에 대한 핵심 답변
- 명확하고 구체적인 정보 제공

#### 2. 🔍 맥락적 설명

- 현재 상황과 컨텍스트를 고려한 상세 설명
- 배경 정보와 함께 종합적 관점 제시

#### 3. 💡 관련 인사이트

- 질문과 관련된 추가적인 통찰력
- 다양한 관점에서의 추가 정보

#### 4. ❓ 후속 질문

- 관련된 추가 질문 제안
- 더 깊이 있는 분석을 위한 질문들

#### 5. 📚 참고 자료

- 분석의 근거가 되는 자료들
- 법규, 정책, 시장 자료 등

#### 6. 🚀 다음 단계

- 실행 가능한 후속 조치 제안
- 구체적인 행동 방안

#### 1. 실행 요약

- 주요 발견사항 정리

#### 2. 상세 분석

- 각 전문 관점별 상세 분석
- 구체적인 데이터와 근거

#### 3. 권장사항

- 실행 가능한 구체적 제안
- 우선순위별 권장사항

## 🎯 효과적인 사용 팁

### 1. 질문 작성 팁

- **구체적으로 질문하기**: "투자 가치가 어떤가요?" → "개포우성 재개발 프로젝트의 5년 예상 수익률은 얼마나 되나요?"
- **관점 명시하기**: "정책적 관점에서", "투자자 관점에서", "주민 관점에서"
- **구체적 상황 제시**: "현재 시장 상황에서", "주민 반발이 있을 경우"

### 2. 대화 연속성 활용

- **이전 대화 참조**: "앞서 말씀하신 투자 가치와 관련해서..."
- **단계적 질문**: 기본 질문 → 상세 질문 → 실행 방안
- **관련 질문 연결**: "그렇다면 리스크 요소는 무엇인가요?"

### 3. 파일 업로드 활용

- **관련 문서 업로드**: 정책 자료, 시장 분석 보고서, 주민 의견서 등
- **다양한 형식 활용**: PDF, Word, Excel, 이미지 등
- **최신 자료 사용**: 최신 정보를 반영한 분석 결과

## 🔧 고급 기능

### 1. 분석 깊이 조정

- **Basic**: 기본적인 정보 제공
- **Intermediate**: 중간 수준의 상세 분석
- **Advanced**: 고급 수준의 종합 분석
- **Expert**: 전문가 수준의 심층 분석

### 2. 대화 히스토리 관리

- **이전 대화 기억**: 시스템이 이전 대화 내용을 기억
- **맥락 유지**: 연속된 대화에서 맥락 유지
- **관련 질문 제안**: 이전 대화를 바탕으로 한 질문 제안

### 3. 파일 컨텍스트 활용

- **업로드된 파일 참조**: 분석 시 업로드된 파일 내용 반영
- **파일 간 연관성 분석**: 여러 파일의 상호 관계 분석
- **최신 정보 반영**: 최근 업로드된 파일 우선 참조

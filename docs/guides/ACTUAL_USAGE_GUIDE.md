# 🎯 **CORBU.AI 고급 응답 시스템 실제 사용 가이드**

## 📋 **시스템 접속 및 시작**

### **1. 시스템 접속**

```
브라우저에서 다음 주소로 접속하세요:
🌐 http://localhost:3000
```

### **2. 초기 화면 확인**

- ✅ **환영 메시지**: "CORBU.AI와 대화를 시작하세요"
- ✅ **헤더 기능**: 사이드 메뉴, 품질 대시보드, 실시간 모니터링, 품질 가이드
- ✅ **입력창**: 자동 크기 조절, 34자 제한, 키보드 단축키 지원
- ✅ **설정 옵션**: 품질, 스타일, 톤, 길이 조절

---

## 🚀 **단계별 사용 시나리오**

### **시나리오 1: 신규 사용자 온보딩**

#### **1단계: 시스템 탐색**

1. **헤더 기능 확인**
   - 📋 **사이드 메뉴**: 프로젝트, 세션, 파일 관리
   - 📊 **품질 대시보드**: 현재 응답의 품질 분석
   - 📈 **실시간 모니터링**: 품질 추이 실시간 추적
   - 📖 **품질 가이드**: 최적화 방법 및 팁

2. **설정 옵션 확인**
   - **품질**: 기본 품질 → 고급 품질 → 궁극 품질
   - **스타일**: 간결 → 균형 → 상세
   - **톤**: 전문적 → 친근 → 중립
   - **길이**: 짧게 → 보통 → 길게

#### **2단계: 첫 번째 질문**

```
입력 예시: "React란 무엇인가요?"
```

**예상 결과:**

- 🎯 **기본 품질**: 간단한 React 소개
- 🚀 **고급 품질**: React의 특징, 장점, 사용 사례 포함
- ⭐ **궁극 품질**: 상세한 기술적 설명과 실제 예제

### **시나리오 2: 응답 품질 비교 테스트**

#### **1단계: 질문 준비**

```
입력 예시: "프로젝트 관리 방법을 알려주세요."
```

#### **2단계: 품질별 비교**

1. **기본 품질** 설정으로 질문
   - 결과: 간단한 프로젝트 관리 개요

2. **고급 품질** 설정으로 동일 질문
   - 결과: 체계적인 관리 방법과 도구 소개

3. **궁극 품질** 설정으로 동일 질문
   - 결과: 상세한 방법론, 사례, 도구, 모범 사례

#### **3단계: 길이별 비교**

1. **짧게** 설정: 핵심만 간결하게
2. **보통** 설정: 균형잡힌 설명
3. **길게** 설정: 상세하고 포괄적인 설명

### **시나리오 3: 고급 기능 테스트**

#### **1단계: 실시간 품질 모니터링**

1. 헤더의 **📈** 버튼 클릭
2. **모니터링 시작** 버튼 클릭
3. 질문을 입력하고 응답 생성
4. 실시간 품질 추이 확인:
   - 📊 **시계열 차트**: 품질 점수 변화
   - 📈 **바 차트**: 차원별 품질 분석
   - 🍩 **도넛 차트**: 품질 분포

#### **2단계: 품질 가이드 활용**

1. 헤더의 **📖** 버튼 클릭
2. **5개 탭** 탐색:
   - 📋 **개요**: 시스템 전체 개요
   - 📊 **품질 차원**: 8차원 품질 평가 설명
   - 💡 **최적화 팁**: 품질 향상 방법
   - 🎯 **예시**: 실제 사용 시나리오
   - 🚀 **고급 기능**: 고급 기능 활용법

#### **3단계: 시스템 통합 테스트**

1. `http://localhost:3000/test` 접속
2. **전체 시스템 테스트 실행** 버튼 클릭
3. **8개 테스트 항목** 확인:
   - 백엔드 연결 테스트
   - 고급 품질 평가 시스템
   - 다중 모델 응답 생성
   - 실시간 품질 모니터링
   - 성능 벤치마크
   - Chart.js 라이브러리
   - 라우팅 시스템
   - 컴포넌트 통합

### **시나리오 4: 입력창 고급 기능 테스트**

#### **1단계: 자동 크기 조절**

1. 입력창에 **짧은 텍스트** 입력
   - 결과: 기본 높이 유지

2. **긴 텍스트** 입력 (34자 초과)
   - 결과: 자동으로 높이 증가

3. **Shift+Enter**로 줄바꿈
   - 결과: 수동 줄바꿈으로 높이 증가

#### **2단계: 키보드 단축키**

1. **Enter**: 메시지 전송
2. **Shift+Enter**: 줄바꿈
3. **Ctrl+Enter**: 메시지 전송 (대안)

#### **3단계: 34자 제한 확인**

1. 입력창 우하단의 **문자 수 표시** 확인
2. 34자 초과 입력 시 **자동 줄바꿈** 확인
3. 대화창에서 **줄바꿈 보존** 확인

## 🚨 **문제 해결**

### **1. 일반적인 문제**

- **응답이 느린 경우**: 품질 설정을 "기본 품질"로 변경
- **응답이 너무 긴 경우**: 길이 설정을 "짧게"로 변경
- **품질이 낮은 경우**: 품질 설정을 "궁극 품질"로 변경

### **2. 기술적 문제**

- **페이지 로딩 안됨**: `http://localhost:3000` 접속 확인
- **백엔드 오류**: 헤더의 백엔드 상태 확인
- **기능 오류**: `http://localhost:3000/test`에서 시스템 테스트 실행

## 주의·팁

- **프로젝트 먼저 선택**: CORBU.AI 메인 대화·노트북 LLM은 **프로젝트를 선택한 뒤** 사용하세요. 선택하지 않으면 대화가 어느 프로젝트에 붙을지 정해지지 않거나, 노트북 LLM에 지침·파일이 반영되지 않을 수 있습니다.
- **저장 확인**: 프로젝트 편집 후 **저장**을 눌러야 반영됩니다. "설정이 저장되었습니다" 토스트가 뜨면 정상입니다. **취소**·**Escape**·바깥 클릭으로 닫으면 저장되지 않습니다.
- **삭제는 복구 불가**: 프로젝트·대화 삭제 후에는 복구할 수 없습니다. 필요한 내용은 미리 복사해 두세요.
- **모달 닫기**: **Escape** 키 또는 모달 바깥 클릭 시 **저장하지 않고** 닫힙니다. 저장하려면 반드시 **저장** 버튼을 누르세요.

## 핵심 3단계

| 목표 | 단계 | 예상 결과 |
|------|------|-----------|
| **첫 대화** | 1) 새 프로젝트 → 이름 입력 → 생성 2) 프로젝트 클릭 3) + 새 대화 → 입력 → Enter | AI 응답이 메인에 표시, 대화 제목 자동 생성 |
| **지침 적용** | 1) 프로젝트 ⋮ → 편집 2) 지침 입력 → 저장 3) 새/기존 대화에서 질문 전송 | "설정이 저장되었습니다" 토스트, 응답에 지침 반영 |
| **TTS** | 1) 고급 기능 → 목소리 생성 2) URL 또는 프로젝트 보이스 선택 3) 텍스트 입력 → 생성/재생 | 선택한 보이스로 음성 재생됨 |

**예상 소요 시간**: 첫 대화 1~2분, 지침 적용 약 2분, TTS 2~3분. 상세 단계·실패 시 대응은 [USAGE_GUIDE §5.6](../../USAGE_GUIDE.md#56-시나리오별-플로우) 참고.

## 실행 전 체크리스트

- **Node.js**: 18 이상 (권장 20). `node -v`로 확인.
- **Python**: 3.8 이상 (백엔드). `python3 --version`으로 확인.
- **포트**: 3000(프론트), 5002(백엔드 통합 API) 사용 가능한지 확인. `lsof -i :3000`, `lsof -i :5002` (macOS/Linux)로 점검.
- **의존성**: `npm install`, `cd backend && pip install -r requirements.txt` 완료 후 실행.
- **실행**: `./start_all.sh` (권장). **종료**: 해당 터미널에서 **Ctrl+C**.

## 접속 주소

| 용도 | 주소 |
|------|------|
| 웹 앱 | http://localhost:3000 |
| API (대화·통합) | http://localhost:5002 |
| API 문서 | http://localhost:5002/api/docs |

**다른 기기에서 접속**: 같은 네트워크에서 `http://<PC IP>:3000`. 방화벽에서 3000·5002 포트 허용 확인.

**데이터 저장**: 대화·프로젝트 정보는 **브라우저 로컬 스토리지**에 저장됩니다. 기기·브라우저마다 다르며, 시크릿/비공개 모드에서는 제한될 수 있습니다.

**지원 브라우저**: Chrome, Firefox, Safari, Edge 최신 버전. JavaScript 활성화 필요.

**프로젝트 파일 형식(참고)**: PDF, DOC/DOCX, TXT, MD, PNG, JPG, JS, TS, TSX, JSON 등. 최대 개수·용량은 백엔드 설정에 따름. 상세는 [USAGE_GUIDE §4.6·§4.7](../../USAGE_GUIDE.md) 참고.

## 첫 실행 후 확인 (체크리스트)

- [ ] http://localhost:3000 접속 시 **CORBU.AI 로고·제목**이 보인다
- [ ] **좌측 사이드바**에 대화·프로젝트·목소리 생성·대화 목록이 보인다
- [ ] **메인 영역**과 **하단 입력창**이 보인다
- [ ] **새 프로젝트** 클릭 시 모달이 열리고, 이름 입력 후 생성하면 목록에 추가된다
- [ ] 프로젝트 선택 후 **+ 새 대화** → 메시지 입력 → Enter 시 메시지가 전송되고(LLM 설정 시) 응답이 표시된다

위 항목이 모두 맞으면 정상 기동된 것입니다. 하나라도 다르면 [문제가 생겼을 때](#문제가-생겼을-때) 또는 [USAGE_GUIDE §8 문제 해결](../../USAGE_GUIDE.md#8-문제-해결) 참고.

## 자주 쓰는 단축키

- **Enter** — 전송
- **Shift+Enter** — 줄바꿈
- **⌘?** 또는 **?** — 단축키 도움말
- **⌘F** — 대화 내 메시지 검색
- **⌘N** — 새 대화
- **Tab** / **Shift+Tab** — 포커스 이동 (메뉴·버튼·입력창 등)
- **Escape** — 모달/사이드바 닫기
- **↑/↓** (입력창 포커스) — 이번 세션 입력 히스토리

## 문제가 생겼을 때

- **프로젝트/대화 안 보임·화면 이상** → F12 Console·Network 확인, 강력 새로고침(**Ctrl+F5** Windows, **Cmd+Shift+R** Mac)
- **저장 안 됨** → "설정이 저장되었습니다" 토스트 확인, 로컬 스토리지 권한 확인
- **LLM 응답 없음** → 환경 변수(LLM_PROVIDER, API 키), 백엔드 실행·포트(5002) 확인. Ollama 사용 시 `ollama list`로 모델 확인
- **노트북 LLM에 프로젝트 반영 안 됨** → CORBU.AI에서 **먼저 프로젝트 선택** 후 노트북 LLM 진입

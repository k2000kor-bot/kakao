## 🛠️ 문제 해결

### 접속이 안 되는 경우
1. 브라우저 캐시 삭제
2. 다른 브라우저로 시도
3. 방화벽 설정 확인

### 기능이 작동하지 않는 경우
1. 페이지 새로고침 (F5)
2. 브라우저 개발자 도구에서 오류 확인
3. 네트워크 연결 상태 확인

## 📞 지원

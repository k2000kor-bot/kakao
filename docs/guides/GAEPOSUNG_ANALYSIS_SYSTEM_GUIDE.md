# 개포우성 재개발 프로젝트 고도화된 분석 시스템 가이드

## 🏢 시스템 개요

개포우성 재개발 프로젝트를 위한 고도화된 다층적 분석 시스템입니다. 다양한 미디어 파일을 업로드하고 다각적 관점에서 종합적인 분석을 제공합니다.

## 🚀 시스템 시작

### 1. 백엔드 서버 시작

```bash
./start_gaeposung_analysis_server.sh
```

### 2. 프론트엔드 서버 시작

```bash
npm start
```

### 3. 접속

- 프론트엔드: <http://localhost:3000>
- 백엔드 API: <http://localhost:5001>

## 🎯 사용 방법

### 1. 프로젝트 설정

1. 사이드바에서 "개포우성7차" 프로젝트 선택
2. "개포우성 분석" 버튼 클릭

### 2. 파일 업로드

1. "파일 관리" 탭에서 파일 선택
2. 지원되는 형식의 파일 업로드
3. 업로드된 파일 확인

### 3. 분석 실행

1. "분석 실행" 탭으로 이동
2. 분석할 파일 선택
3. 분석 타입 선택 (종합/빠른 분석)
4. 분석 시작

### 4. 결과 확인

1. "분석 결과" 탭에서 결과 확인
2. 각 관점별 상세 분석 내용 검토
3. 권장사항 및 리스크 평가 확인

- **Python Flask**: RESTful API 서버

- **Axios**: API 통신

- **실시간 업데이트**: 분석 상태 모니터링

- **데이터 지속성**: 분석 결과 저장 및 관리

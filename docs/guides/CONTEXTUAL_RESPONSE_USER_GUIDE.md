# 🎯 맥락 기반 정확한 답변 시스템 사용자 가이드

## 📖 개요

맥락 기반 정확한 답변 시스템은 사용자의 의도를 파악하여 더 정확하고 확인할 수 있는 답변을 제공하는 고급 AI 시스템입니다. 불명확한 질문에 대해서는 확인 질문을 생성하고, 구체적인 질문에 대해서는 정확한 답변을 제공합니다.

## ✨ 주요 기능

### 🧠 사용자 의도 분석

- 메시지의 의도를 자동으로 분석
- 질문, 요청, 비교, 일반 대화 등 분류
- 신뢰도 점수 계산 및 표시

### 🤔 확인 질문 생성

- 불명확한 표현 감지 ("이것", "그것", "저것" 등)
- 모호한 표현 감지 ("좀", "약간", "대략" 등)
- 의도가 명확하지 않을 때 확인 질문 생성

### ✅ 정확한 답변 제공

- 맥락을 고려한 적응형 응답
- 신뢰도에 따른 응답 조정
- 참고 자료 및 소스 정보 제공

### 📚 맥락 히스토리 관리

- 이전 대화 내용 기억
- 대화 흐름 분석
- 개인화된 응답 생성

### 💡 제안사항 제공

- 확인 질문 시 구체적인 제안사항 표시
- 클릭하여 바로 사용 가능
- 상황별 맞춤 제안

### 👍 응답 품질 평가

- 답변에 대한 피드백 수집
- 개선사항 자동 도출
- 지속적인 시스템 개선

## 🎮 사용 방법

### 1. 기본 사용법

**브라우저에서 접속**: <http://localhost:3000>
**"맥락 기반 답변" 탭 클릭**

### 2. 메시지 입력 예시

#### 불명확한 질문 (확인 질문 생성)

```
사용자: "이것에 대해 알려주세요"
AI: 🤔 확인이 필요합니다:

'이것에 대해 알려주세요'에 대해 더 자세히 설명해주세요. 정확히 어떤 도움이 필요하신가요?

💡 제안사항:
• 더 구체적으로 설명해주세요
• 예시를 들어 설명해주세요
• 어떤 상황에서 필요한지 알려주세요
```

#### 구체적인 질문 (정확한 답변)

```
사용자: "AI 기술의 현재 발전 상황과 미래 전망에 대해 알려주세요"
AI: ✅ 정확한 답변:

💭 'AI 기술의 현재 발전 상황과 미래 전망에 대해 알려주세요'에 대해 답변드리겠습니다. 더 자세한 정보가 필요하시면 말씀해주세요.

이 답변이 도움이 되는지 알려주세요.

📚 참고 자료: 일반적인 정보, 기본 가이드, 참고 자료
🎯 신뢰도: 52.5%
```

### 3. 응답 품질 평가

답변 후 하단에 나타나는 버튼을 클릭하여 피드백을 제공할 수 있습니다:

- **👍 도움됨**: 답변이 도움이 되었다고 평가
- **👎 도움 안됨**: 답변이 도움이 되지 않았다고 평가

### 4. 제안사항 활용

확인 질문이 나타날 때 제안사항을 클릭하면 입력창에 자동으로 입력됩니다.

## 🎨 UI 특징

### 메시지 타입별 색상 구분

- **확인 질문**: 노란색 배경 (`bg-yellow-100`)
- **정확한 답변**: 초록색 배경 (`bg-green-100`)
- **에러 메시지**: 빨간색 배경 (`bg-red-100`)
- **일반 메시지**: 흰색 배경 (`bg-white`)

### 아이콘 시스템

- **확인 질문**: ⚠️ 경고 아이콘
- **정확한 답변**: ✅ 체크 아이콘
- **에러 메시지**: ❌ 에러 아이콘
- **일반 메시지**: ✨ 스파클 아이콘

### 실시간 상태 표시

- **서버 연결 상태**: 녹색/빨간색 점으로 표시
- **타이핑 상태**: 애니메이션 점으로 표시
- **맥락 정보**: 토글 버튼으로 접근

## 🔧 고급 기능

### 맥락 정보 패널

- **맥락 정보** 버튼을 클릭하여 상세 정보 확인
- 대화 길이, 세션 ID, 연결 상태, 제안사항 수 표시

### 제안사항 영역

- 확인 질문 시 관련 제안사항 표시
- 클릭하여 바로 사용 가능
- 파란색 배경으로 구분

### 응답 품질 평가

- 답변 후 피드백 수집
- 개선사항 자동 도출
- 시스템 학습에 활용

## 🎯 사용 팁

### 1. 효과적인 질문하기

- **구체적으로 질문하기**: "AI 기술" 대신 "AI 기술의 현재 발전 상황"
- **예시 포함하기**: "이런 상황에서 어떻게 해야 할까요?"
- **목적 명시하기**: "학습 목적으로", "업무용으로" 등

### 2. 확인 질문 활용하기

- 제안사항을 참고하여 더 구체적으로 질문
- 예시를 들어 설명하기
- 상황을 자세히 설명하기

### 3. 피드백 제공하기

- 정확한 피드백으로 시스템 개선에 기여
- 개선사항을 확인하여 시스템 발전 방향 파악

## 🔍 문제 해결

### 서버 연결 문제

- **상태**: 빨간색 점 표시
- **해결**: 서버가 실행 중인지 확인
- **재시도**: 페이지 새로고침

### 응답 지연

- **원인**: 서버 부하 또는 네트워크 문제
- **해결**: 잠시 후 다시 시도
- **확인**: 타이핑 애니메이션 확인

### 확인 질문이 계속 나타나는 경우

- **원인**: 질문이 여전히 불명확함
- **해결**: 제안사항을 참고하여 더 구체적으로 질문
- **팁**: "무엇을", "어떻게", "왜" 등의 질문어 사용

# 미디어 파일 분석 및 대화체 글쓰기 시스템 가이드

## 📋 개요

이 시스템은 다양한 미디어 파일(이미지, 비디오, 오디오, 문서)을 업로드하고 AI가 분석하여 텍스트로 변환한 후, 글쓰기 지식과 인용 이론을 활용하여 대화체로 응답을 생성하는 기능을 제공합니다.

## 🚀 주요 기능

### 1. 미디어 파일 업로드 및 분석

- **지원 형식**: 이미지, 비디오, 오디오, PDF, Word, 텍스트 파일
- **분석 기능**:
  - 이미지: OCR을 통한 텍스트 추출
  - 비디오: 오디오 및 시각적 정보 종합 분석
  - 오디오: 음성인식을 통한 텍스트 변환
  - 문서: 구조 분석 및 키워드 추출

### 2. 글쓰기 이론 적용

- **인용 이론**: 분석된 내용에서 핵심 문구를 인용하여 주장 강화
- **대화체 글쓰기**: 자연스럽고 이해하기 쉬운 대화체 응답 생성
- **맥락 기반 글쓰기**: 상황에 맞는 적절한 내용과 톤 선택

### 3. 대화체 응답 생성

- 분석된 미디어 내용을 바탕으로 대화체 응답
- 글쓰기 이론을 적용한 구조화된 답변
- 사용자 질문에 따른 맞춤형 응답

## 🛠️ 설치 및 실행

### 1. 백엔드 서버 시작

```bash
# 미디어 분석 서버 시작
./start_media_analysis_server.sh
```

### 2. 프론트엔드 실행

```bash
# React 개발 서버 시작
npm start
```

## 📖 사용 방법

### 1. 파일 업로드

1. 왼쪽 사이드바의 "파일 선택" 버튼 클릭
2. 분석하고 싶은 미디어 파일 선택 (다중 선택 가능)
3. 파일이 자동으로 업로드되고 분석 시작

### 2. 글쓰기 이론 선택

1. 하단의 "글쓰기 이론 선택" 버튼 클릭
2. 원하는 이론 선택:
   - **인용 이론**: 다른 사람의 말이나 글을 적절히 인용
   - **대화체 글쓰기**: 자연스러운 대화처럼 읽기 쉬운 글쓰기
   - **맥락 기반 글쓰기**: 상황에 맞는 적절한 내용과 톤

### 3. 대화 시작

1. 메인 영역의 입력 필드에 질문 입력
2. 선택된 파일들이 자동으로 첨부됨
3. AI가 분석된 내용을 바탕으로 대화체 응답 생성

## 📊 분석 결과 구조

### MediaFile 인터페이스

```typescript
interface MediaFile {
  id: string;
  name: string;
  type: 'image' | 'video' | 'audio' | 'document';
  size: number;
  url: string;
  uploadDate: string;
  analysisStatus: 'pending' | 'processing' | 'completed' | 'error';
  extractedText?: string;
  summary?: string;
  keywords?: string[];
  sentiment?: string;
  writingInsights?: WritingInsight[];
}
```

### WritingInsight 인터페이스

```typescript
interface WritingInsight {
  id: string;
  type: 'quote' | 'reference' | 'argument' | 'example' | 'statistic';
  content: string;
  source?: string;
  confidence: number;
  context: string;
  writingStyle: string;
  citationFormat: string;
}
```

## 🎨 글쓰기 이론 상세

### 1. 인용 이론 (Citation Theory)

- **목적**: 다른 사람의 말이나 글을 적절히 인용하여 자신의 주장을 뒷받침
- **원칙**:
  - 정확한 출처 표시
  - 적절한 인용 형식 사용
  - 인용과 자신의 의견 구분
  - 맥락에 맞는 인용 선택
- **예시**: `"인용은 자신의 주장을 강화하는 강력한 도구입니다." (김철수, 2023)`

### 2. 대화체 글쓰기 (Conversational Writing)

- **목적**: 자연스러운 대화처럼 읽기 쉽고 이해하기 쉬운 글쓰기
- **원칙**:
  - 간결하고 명확한 문장
  - 일상적인 표현 사용
  - 독자와의 연결감 형성
  - 자연스러운 흐름 유지
- **예시**: "이런 식으로 보시면 됩니다.", "말씀하신 대로 정말 중요한 부분이에요."

### 3. 맥락 기반 글쓰기 (Context-Based Writing)

- **목적**: 주어진 상황과 배경을 고려하여 적절한 내용과 톤을 선택
- **원칙**:
  - 상황에 맞는 어조 선택
  - 대상 독자 고려
  - 목적에 맞는 내용 구성
  - 적절한 예시와 설명
- **예시**: "이 상황에서는 이런 접근이 효과적일 것 같아요."

## 🔍 고급 기능

### 1. 배치 파일 처리

- 여러 파일을 동시에 업로드하고 분석
- 진행 상황 실시간 모니터링

### 2. 분석 상태 폴링

- 파일 분석 완료까지 자동 대기
- 최대 30회 시도 (60초)

### 3. 글쓰기 인사이트 필터링

- 인사이트 타입별 필터링
- 신뢰도 기반 정렬
- 소스별 분류

## 🚨 주의사항

1. **파일 크기 제한**: 대용량 파일은 분석 시간이 오래 걸릴 수 있습니다.
2. **지원 형식**: 이미지, 비디오, 오디오, PDF, Word, 텍스트 파일만 지원됩니다.
3. **인터넷 연결**: 파일 업로드와 분석을 위해 안정적인 인터넷 연결이 필요합니다.
4. **서버 상태**: 백엔드 서버가 실행 중이어야 합니다.

## 🚀 시작하기

### 1. 시스템 접속
- 브라우저에서 `http://localhost:3000` 접속
- 시스템이 자동으로 로드됩니다

### 2. 초기 설정
- 우측 상단 설정 버튼 클릭
- API 키들을 입력 (선택사항)

## 💬 기본 사용법

### ChatGPT 스타일 입력
- 하단 입력창에 메시지 입력
- 자동 높이 조절 (최대 120px)
- 실시간 글자 수 및 단어 수 표시
- 예상 읽기 시간 표시

### 고급 입력 기능
- **스마트 제안**: 타이핑 중 자동 제안
- **입력 히스토리**: Ctrl+Up/Down으로 이전 메시지 탐색
- **파일 업로드**: 드래그 앤 드롭 지원
- **명령어 모드**: `/` 입력으로 특별 명령어 실행

### 명령어 목록
- `/help` - 도움말 표시
- `/clear` - 대화 기록 삭제
- `/export` - 대화 내보내기
- `/settings` - 설정 열기
- `/search` - 검색 모드
- `/theme` - 테마 변경
- `/voice` - 음성 모드
- `/file` - 파일 업로드

## 🤖 AI 서비스 설정

### 1. API 키 설정
1. 우측 상단 설정 버튼 클릭
2. "API 키 설정" 섹션에서 각 서비스의 키 입력:
   - **Gemini API**: Google AI Studio에서 발급
   - **OpenAI API**: OpenAI 플랫폼에서 발급
   - **Claude API**: Anthropic에서 발급
   - **News API**: NewsAPI.org에서 발급

### 2. AI 모델 선택
- 드롭다운에서 원하는 AI 모델 선택:
  - Gemini Pro (Google)
  - GPT-4 (OpenAI)
  - Claude-3 (Anthropic)

### 3. 실시간 AI 응답
- 메시지 전송 후 선택된 AI 모델이 실시간으로 응답
- 응답 품질 및 속도 모니터링

## 📰 뉴스 검색 및 분석

### 1. 뉴스 검색 모드
- 좌측 사이드바에서 "뉴스 검색" 클릭
- 검색창에 키워드 입력
- 실시간 뉴스 검색 결과 표시

### 2. 댓글 분석
- 뉴스 기사 클릭 시 댓글 분석 자동 실행
- 감정 분석 결과 표시
- 키워드 추출 및 트렌드 분석

### 3. 트렌딩 뉴스
- 자동으로 최신 트렌딩 뉴스 수집
- 카테고리별 분류
- 실시간 업데이트

## 📊 실시간 모니터링

### 1. 시스템 상태
- 좌측 사이드바에서 "모니터링" 클릭
- 실시간 시스템 건강도 확인
- CPU, 메모리, 네트워크 사용량 모니터링

### 2. 성능 지표
- **응답 시간**: 평균 AI 응답 시간
- **활성 사용자**: 현재 접속 중인 사용자 수
- **총 알림**: 시스템 알림 개수
- **AI 모델 성능**: 정확도 및 추론 시간

### 3. 알림 시스템
- 실시간 시스템 알림
- 중요도별 분류 (정보, 경고, 심각)
- 자동 해결 상태 추적

## 👥 협업 기능

### 1. 협업자 관리
- 좌측 사이드바에서 "협업" 클릭

- **집중시간**: 실제 작업 시간
- **완료작업**: 완료된 작업 수

### 3. 실시간 상태
- 온라인/오프라인 상태
- 타이핑 중 표시
- 현재 작업 내용 표시

### 4. 공유 노트
- 팀원들과 노트 공유
- 실시간 편집 및 수정
- 버전 관리

## 🛠️ 문제 해결

### 자주 발생하는 문제

#### 1. AI 응답이 나오지 않을 때
- API 키가 올바르게 설정되었는지 확인
- 인터넷 연결 상태 확인
- AI 모델 선택 확인

#### 2. 뉴스 검색이 작동하지 않을 때
- News API 키 설정 확인
- 검색어가 올바른지 확인
- 네트워크 연결 상태 확인

#### 3. 시스템이 느릴 때
- 브라우저 새로고침
- 다른 탭에서 실행 중인 프로그램 확인
- 시스템 모니터링에서 성능 지표 확인

#### 4. 협업 기능이 작동하지 않을 때
- 인터넷 연결 상태 확인
- 브라우저 새로고침
- 설정에서 협업 기능 활성화 확인

### 기술 지원

문제가 지속될 경우:
1. 브라우저 개발자 도구에서 오류 확인
2. 시스템 로그 확인
3. 개발팀에 문의

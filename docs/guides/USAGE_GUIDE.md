# CORBU AI 시스템 사용 가이드

## 🚀 시작하기

1. **브라우저에서 `http://localhost:3000` 접속**
2. **화면 좌상단에 빨간색 "ChatGPTMode 컴포넌트" 라벨이 보이는지 확인**

## 📁 프로젝트 관리

### 프로젝트 선택

1. **왼쪽 사이드바에서 프로젝트 클릭**
   - "개포우성7차" 프로젝트 선택
   - "대화요약" 프로젝트 선택
   - 기타 프로젝트들

### 새 프로젝트 생성

1. **"새 프로젝트" 버튼 클릭**
2. **프로젝트 이름 입력** (예: "내 첫 프로젝트")
3. **"프로젝트 만들기" 버튼 클릭**

## 📎 파일 관리

### 프로젝트 파일 추가

1. **"파일 추가" 버튼 클릭**
2. **파일 선택** (여러 파일 동시 선택 가능)
3. **파일이 프로젝트에 추가됨**

### 채팅에 파일 첨부

1. **파일을 입력창에 드래그 앤 드롭**
2. **또는 파일 선택 후 입력창에 붙여넣기**
3. **파일이 채팅에 첨부됨**

## 💡 지침 설정

### 프로젝트 지침 설정

1. **"지침 추가" 버튼 클릭**
2. **지침 입력** (예: "항상 한국어로 답변해주세요")
3. **"저장" 버튼 클릭**

## 💬 채팅 테스트

### 기본 채팅

1. **입력창에 질문 입력** (예: "안녕하세요")
2. **전송 버튼 클릭**
3. **AI 응답 확인**

### 프로젝트 컨텍스트 테스트

1. **프로젝트 선택** (지침이 설정된 프로젝트)
2. **질문 입력** (예: "이 프로젝트에 대해 설명해주세요")
3. **프로젝트 정보가 포함된 AI 응답 확인**

### 파일 첨부 테스트

1. **파일을 입력창에 드래그 앤 드롭**
2. **질문 입력** (예: "이 파일을 분석해주세요")
3. **파일 정보가 포함된 AI 응답 확인**

## 🐛 문제 해결

### 화면이 로드되지 않는 경우

1. **브라우저 새로고침** (Ctrl+F5)
2. **개발자 도구 확인** (F12)
3. **네트워크 탭에서 오류 확인**

### 기능이 작동하지 않는 경우

1. **브라우저 콘솔 확인** (F12 → Console)
2. **오류 메시지 확인**
3. **서버 재시작** (터미널에서 Ctrl+C 후 npm start)

## 📞 지원

문제가 발생하면 다음 정보를 제공해주세요:

- 브라우저 종류 및 버전
- 오류 메시지 (있다면)
- 수행하려던 작업
- 화면 스크린샷 (가능한 경우)

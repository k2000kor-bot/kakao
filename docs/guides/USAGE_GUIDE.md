# CORBU.AI 시스템 사용 가이드 (guides)

**CORBU.AI 화면·메뉴·프로젝트·대화·파일·지침·기능 확인을 위한 가이드입니다.**

**개발·검증**: [TESTING_GUIDE.md](../../TESTING_GUIDE.md) — `npm run test:routes`·`test:app-unified`·**`test:sidebar-context`**. 원격 `git push` 막힘 — [PUSH_BLOCK_HANDOFF.md](../PUSH_BLOCK_HANDOFF.md).

---

## 1. 시작하기

1. **브라우저에서 `http://localhost:3000` 접속**
2. **사이드바**: 대화(/), 프로젝트(/projects), 목소리 생성(/voice-generation) 메뉴 확인
3. **메인 영역**: 선택한 메뉴에 따른 대화/기능 화면 표시

**예상 결과**: CORBU.AI 로고·제목, 좌측 사이드바(대화·프로젝트·목소리 생성·대화 목록), 메인 영역, 하단 입력창이 보이면 정상입니다.

**주의**: 대화·노트북 LLM을 쓰려면 **반드시 먼저 프로젝트를 선택**하세요. 선택하지 않으면 새 대화가 어느 프로젝트에 붙을지 정해지지 않거나, 노트북 LLM에 지침·파일이 반영되지 않을 수 있습니다.

---

## 2. 프로젝트 관리

### 2.1 프로젝트 선택

- **사이드바** 프로젝트 목록에서 원하는 프로젝트 클릭
- 선택된 프로젝트의 대화만 표시되며, 새 대화도 해당 프로젝트에 연결됨

### 2.2 새 프로젝트 생성

1. **"새 프로젝트"** 버튼 클릭 (사이드바 프로젝트 영역 상단)
2. **프로젝트 이름** 입력 (예: `내 첫 프로젝트`, `테스트` — 필수)
3. **"프로젝트 만들기"** 또는 **"생성"** 클릭
4. 모달이 닫히고 목록에 새 프로젝트가 나타나면 **클릭해 선택**

**예상 결과**: "설정이 저장되었습니다" 또는 생성 완료 후 모달 닫힘, 사이드바에 새 이름 표시.

### 2.3 프로젝트 편집·삭제·공유

- 프로젝트 항목 오른쪽 **⋮(점 세 개)** 클릭
- **편집**: 이름·설명·태그·지침·프로젝트 파일 수정 후 **저장** 클릭 (토스트로 반영 확인)
- **삭제**: 프로젝트 및 해당 대화 삭제 (복구 불가. 필요한 내용은 미리 복사)
- **공유**: 공유 모달에서 링크 생성·권한 설정 후 다른 사용자와 공유. 상세는 루트 [USAGE_GUIDE §4.5](../../USAGE_GUIDE.md) 참고

## 3. 파일·지침

### 3.1 프로젝트 파일 추가

1. 프로젝트 **⋮** → **편집** (또는 편집 모달 내 **"파일 추가"**)
2. **파일 선택** (여러 파일 동시 선택 가능)
3. 업로드 완료 후 목록에 표시. 대화 시 프로젝트 맥락(projectKnowledge)으로 참고됨

### 3.2 대화에 파일 첨부 (메시지별)

- **드래그 앤 드롭**: 파일을 **입력창**에 끌어다 놓기
- **선택**: 파일 선택 후 입력창에 붙여넣기
- 첨부된 파일은 **해당 메시지와 함께만** 전송됨 (프로젝트 파일과 구분: 프로젝트 파일은 편집 모달에서 추가하고 모든 대화에서 참고됨)

### 3.3 프로젝트 지침 설정

1. 프로젝트 **⋮** → **편집**
2. **지침** 입력 (예: "항상 한국어로 답변해주세요", "보고서 톤 유지")
3. **저장** 클릭
4. 해당 프로젝트 내 모든 대화에 공통 적용됨 (백엔드 projectKnowledge·지침 반영)

---

## 4. 대화 테스트

### 4.1 기본 대화

1. **프로젝트 선택** (사이드바) → **"+ 새 대화"** 클릭
2. **입력창**에 질문 입력 (예: `안녕하세요`)
3. **Enter** 또는 **전송** 클릭
4. **AI 응답** 확인 (LLM 설정에 따라 동작)

**예상 결과**: 입력창 비워짐, 사용자 메시지·AI 응답이 메인에 표시, 사이드바 대화 목록에 제목 자동 생성.

### 4.2 프로젝트 컨텍스트 테스트

1. **지침·파일이 설정된 프로젝트** 선택
2. 질문 입력 (예: `이 프로젝트에 대해 설명해주세요`)
3. **프로젝트 정보·지침이 반영된 AI 응답** 확인

**예상 결과**: 응답에 지침(예: 한국어·존댓말) 또는 프로젝트 파일 내용이 반영됨.

### 4.3 파일 첨부 테스트

1. **파일을 입력창에 드래그 앤 드롭** (또는 선택 후 붙여넣기)
2. 질문 입력 (예: `이 파일을 분석해주세요`)
3. **파일 정보가 반영된 AI 응답** 확인

**예상 결과**: 해당 메시지에 파일이 첨부된 상태로 전송되고, 응답에 파일 맥락이 반영됨. 시나리오·예상 결과 상세는 루트 [USAGE_GUIDE §5.6](../../USAGE_GUIDE.md) 참고.

## 6. 문제 해결

### 6.1 화면이 로드되지 않음

1. **강력 새로고침** (Ctrl+F5)
2. **개발자 도구** (F12) → Console·Network 탭에서 오류 확인
3. **포트 확인**: 3000(프론트), 5002(백엔드 통합 API) 사용 여부

### 6.2 기능이 작동하지 않음

1. **브라우저 콘솔** (F12 → Console) 오류 메시지 확인
2. **네트워크** 탭에서 API 요청 실패 여부 확인
3. **서버 재시작**: 터미널에서 Ctrl+C 후 `./start_all.sh` 또는 `npm start`·`./backend/start.sh`

### 6.3 지원 시 제공할 정보

- 브라우저 종류 및 버전
- 오류 메시지 (있다면)
- 수행하려던 작업
- 화면 스크린샷 (가능한 경우)

**상세 원인·조치**: 루트 [USAGE_GUIDE §8 문제 해결](../../USAGE_GUIDE.md#8-문제-해결) 참고.

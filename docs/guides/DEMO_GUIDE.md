#### 1.1 웹 브라우저 열기

```
http://localhost:3000
```

#### 1.2 초기 화면 확인
- ✅ React App 로딩 확인

## 📁 파일 업로드 데모

### 2단계: 파일 업로드 기능 테스트

#### 2.1 사이드바에서 파일 업로드 시작
1. 사이드바에서 **"파일 업로드"** 버튼 클릭
2. 고급 파일 업로드 모달이 열리는지 확인

#### 2.2 드래그 앤 드롭 테스트
1. 생성된 테스트 파일 중 하나를 선택
2. 파일을 업로드 영역으로 드래그
3. 드롭하여 업로드 시작
4. 실시간 진행률 확인

#### 2.3 다중 파일 업로드 테스트
1. 여러 테스트 파일을 동시에 선택
2. "파일 선택" 버튼을 통해 업로드
3. 병렬 처리 진행률 확인

**테스트 파일 목록**:
- `test_document.txt` - 기본 테스트 문서
- `emotion_test_document.txt` - 감정 분석 테스트
- `test_document_advanced.txt` - 고급 기능 테스트
- `corbu_test_document.txt` - CORBU.AI 테스트

## 🧪 API 테스트 데모

### 7단계: 백엔드 API 테스트

#### 7.1 ChatGPT 분석 API 테스트
```bash
curl -X POST "http://localhost:5002/api/v7/chatgpt/analyze" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "CORBU.AI 시스템은 고급 파일 업로드, AI 학습, 실시간 협업 기능을 제공합니다.",
    "room_id": "demo-room",
    "analysis_mode": "advanced",
    "ai_analysis": true
  }'
```

#### 7.2 감정 분석 API 테스트
```bash
curl -X POST "http://localhost:5002/api/v7/analyze-emotion" \

  -d '{
    "text": "CORBU.AI 시스템이 정말 훌륭합니다!",
```

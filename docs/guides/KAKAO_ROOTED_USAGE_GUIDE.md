# 🔓 카카오톡 루팅폰 추출 시스템 완전 사용 가이드

> **CORBU 메인 웹·대화 API**는 통합 백엔드 **포트 5002** (`main_server`, `/api/docs`) 입니다.  
> 아래 **8005** 주소는 **`rooted_kakao_extractor.py` 단독 서버** 전용입니다 (통합 서버와 별개).

## 📱 시스템 개요

루팅된 Android 폰에서 카카오톡 데이터베이스에 직접 접근하여 실시간으로 대화 내용을 추출하고 CORBU.AI 시스템으로 전송하는 완전한 솔루션입니다.

### ✅ 주요 기능

- **실시간 모니터링**: 카카오톡 DB 파일 변화 감지
- **자동 추출**: 새 메시지 즉시 추출 및 전송
- **완전한 데이터**: 삭제된 메시지도 복구 가능
- **미디어 지원**: 이미지, 동영상, 음성 파일 원본 접근
- **선택적 모니터링**: 특정 대화방만 선택 가능
- **웹 시스템 연동**: CORBU.AI와 완전 통합

## 🚀 빠른 시작

### 1️⃣ PC 서버 실행

```bash
# 프로젝트 루트에서
cd backend
python rooted_kakao_extractor.py

# 또는 스크립트 사용
./start_rooted_kakao_server.sh
```

**서버 정보:**

- **주소**: <http://localhost:8005>
- **API 문서**: <http://localhost:8005/docs>
- **상태 확인**: <http://localhost:8005/api/rooted/get-monitored-rooms>

### 2️⃣ Android 앱 설치

#### APK 파일 위치

```
/path/to/kakao-frontend/kakao-frontend/android_app/KakaoRootExtractor/app/build/outputs/apk/debug/KakaoRootExtractor_v1.0.0_debug_20250726_1930.apk
```

#### 설치 방법

```bash
# ADB 사용 (권장)
adb install KakaoRootExtractor_v1.0.0_debug_20250726_1930.apk

# 또는 파일 매니저 사용
1. APK 파일을 폰으로 전송
2. 파일 매니저에서 APK 터치
3. "설치" 버튼 터치
```

### 3️⃣ 루팅폰 설정

#### 필수 설정

1. **개발자 옵션 활성화**
   - 설정 > 휴대전화 정보 > 빌드 번호 7번 터치

2. **USB 디버깅 활성화**
   - 설정 > 개발자 옵션 > USB 디버깅 체크

3. **알 수 없는 소스 허용**
   - 설정 > 보안 > 알 수 없는 소스 체크

4. **루트 권한 확인**

   ```bash
   # 터미널 앱에서
   su
   # "Permission granted" 또는 # 프롬프트 나타나면 성공
   ```

## 🔧 데이터베이스 구조

### 카카오톡 주요 테이블

```sql
-- 메시지 데이터
chat_logs:
- _id: 메시지 ID
- chat_id: 대화방 ID  
- user_id: 보낸 사람 ID
- nickname: 보낸 사람 이름
- message: 메시지 내용
- type: 메시지 타입 (1=텍스트, 2=이미지...)
- created_at: 생성 시간
- attachment: 첨부파일 경로

-- 대화방 정보
open_chat_link:
- id: 대화방 ID
- nickname: 대화방 이름
- type: 대화방 타입 (1=개인, 2=그룹, 3=오픈대화)
- member_count: 참여자 수
- members: 참여자 목록
```

### 로컬 데이터베이스

```sql
-- 추출된 메시지
extracted_messages:
- id: 자동 증가 ID
- message_id: 카카오톡 메시지 ID
- chat_room_id: 대화방 ID
- sender_id: 보낸 사람 ID
- sender_name: 보낸 사람 이름
- content: 메시지 내용
- message_type: 메시지 타입
- timestamp: 타임스탬프
- is_sent_by_me: 내가 보낸 메시지 여부
- attachment_path: 첨부파일 경로
- extracted_at: 추출 시간
- processed: 처리 완료 여부

-- 대화방 정보
chat_rooms:
- id: 자동 증가 ID
- room_id: 대화방 ID
- room_name: 대화방 이름
- room_type: 대화방 타입
- participant_count: 참여자 수
- participants: 참여자 목록 (JSON)
- last_message_time: 마지막 메시지 시간
- created_at: 생성 시간
- updated_at: 업데이트 시간
```

## 🔄 동작 원리

### 실시간 모니터링

```kotlin
// FileObserver로 DB 파일 변화 감지
fileObserver = object : FileObserver(dbFolder, MODIFY) {
    override fun onEvent(event: Int, path: String?) {
        if (path?.contains("KakaoTalk") && path.endsWith(".db")) {
            extractNewMessages() // 새 메시지 즉시 추출
        }
    }
}
```

### 데이터 추출 프로세스

1. **파일 변화 감지**: 카카오톡 DB 파일 수정 감지
2. **새 메시지 추출**: SQLite 쿼리로 새 메시지 조회
3. **데이터 정제**: 메시지 형식 정규화
4. **네트워크 전송**: PC 서버로 HTTP POST 전송
5. **로컬 저장**: 추출된 데이터 로컬 DB 저장

### 웹 시스템 연동

1. **데이터 수신**: 루팅폰 서버에서 메시지 수신
2. **파싱 처리**: `advanced_kakao_parser.py`로 분석
3. **AI 분석**: CORBU.AI 시스템에서 대화 분석
4. **웹 표시**: 프론트엔드에서 결과 표시

# 🤖 지능형 응답 엔진 테스트 가이드

## 🎯 개요

CORBU.AI 시스템의 **지능형 응답 생성 엔진**이 완성되었습니다. 이 엔진은 질문을 정확히 파악하고 실제 답변을 생성하는 고도화된 시스템입니다.

## 📍 현재 상태

- **시스템 실행**: <http://localhost:3002>
- **🤖 지능형 응답 엔진**: 100% 완성 및 통합 완료
- **📊 응답 품질 지표**: 실시간 측정 시스템 활성화
- **🔍 고도화된 NLP 분석**: 복잡한 질문 분해 및 다층적 분석
- **🌐 웹검색 지식 통합**: 다중 소스 정보 통합 시스템

## 🧪 테스트 시나리오

### 1. 🤖 기본 지능형 응답 테스트

#### 테스트 질문 1: 간단한 정보 요청

```
안녕하세요, 간단한 질문을 해도 될까요?
```

**예상 분석 결과:**

- 질문 유형: factual (사실 확인)
- 복잡도: 1-2/10
- 의도: 정보 요청 + 정중한 표현
- 도메인: general (일반)
- 응답 형식: conversational (대화형)

#### 테스트 질문 2: 기술적 질문

```
React에서 상태 관리는 어떻게 하나요?
```

**예상 분석 결과:**

- 질문 유형: procedural (절차적)
- 복잡도: 4-5/10
- 의도: 정보 탐색 + 방법 요청
- 도메인: technology (기술)
- 응답 형식: detailed (상세)

### 2. 🔍 복잡한 질문 분해 테스트

#### 테스트 질문 3: 다중 요구사항 질문

```
원베일리 아파트 하자 문제에 대해 최근 뉴스를 검색하고, 주민들의 댓글 반응을 분석해서 정리해주고, 법적 대응 방안도 함께 제시해줘
```

**예상 분석 결과:**

- 질문 유형: analytical (분석적)
- 복잡도: 8-9/10
- 의도: 정보 수집 + 분석 + 조언 요청
- 도메인: realestate (부동산)
- 응답 형식: structured (구조화)

#### 테스트 질문 4: 암시적 요구사항 포함

```
AI 개발 프로젝트를 시작하려고 하는데, 프론트엔드는 React로 하고 백엔드는 뭐가 좋을지 추천해주고, 팀 구성은 어떻게 해야 할지, 그리고 예산은 대략 얼마나 필요한지 알고 싶어
```

**예상 분석 결과:**

- 질문 유형: creative (창의적)
- 복잡도: 7-8/10
- 의도: 기술 조언 + 인력 계획 + 비용 추정
- 도메인: technology, business
- 응답 형식: comprehensive (포괄적)

### 3. 📊 응답 품질 지표 테스트

각 질문 후 다음 품질 지표를 확인하세요:

#### 품질 지표 확인 방법

1. 질문 입력 후 AI 응답 생성
2. 헤더 우측의 **🤖 지능형 응답 분석** 버튼 클릭
3. **응답 품질** 섹션에서 다음 지표 확인:
   - **관련성**: 질문과 응답의 관련성 (0-100%)
   - **완성도**: 응답의 완전성 (0-100%)
   - **정확성**: 정보의 정확성 (0-100%)
   - **명확성**: 표현의 명확성 (0-100%)
   - **유용성**: 실제 활용 가능성 (0-100%)

### 4. 🎯 고도화된 분석 패널 테스트

#### 분석 패널 확인 방법

1. **💡 고도화된 질문 분석** 버튼 클릭
2. 다음 섹션들을 확인:
   - **질문 구성 요소**: 각 구성 요소의 타입, 우선순위, 복잡도
   - **응답 전략**: 톤, 깊이, 상호작용 요소
   - **다층적 분석**: 표면, 심층, 메타 분석 결과
   - **통합 지식**: 신뢰도 분석, 지식 공백 식별

#### 지능형 응답 분석 패널 확인 방법

1. **🤖 지능형 응답 분석** 버튼 클릭
2. 다음 섹션들을 확인:
   - **질문 컨텍스트**: 유형, 복잡도, 도메인, 의도
   - **응답 품질**: 5가지 품질 지표 실시간 측정
   - **생성된 응답**: 최적화된 응답 내용
   - **분석 정보**: 신뢰도, 출처, 추론 과정
   - **후속 제안**: 추천 질문, 관련 주제

### 유시민 스타일·학습·딥러닝 샘플

유시민 스타일 학습·딥러닝 시스템(분야별 지식·논리 구조·질문 프레임워크) 적용 샘플:
- [롯데건설_성수4지구_유시민스타일_2300자.md](./롯데건설_성수4지구_유시민스타일_2300자.md) — 질문으로 시작·말의 포장 벗기기·표 비교·반론 검토·인용 포함

### 일반적인 문제들:

1. **분석 패널이 열리지 않는 경우**
   - 질문을 입력하고 AI 응답이 생성된 후 버튼 클릭
   - 브라우저 새로고침 후 재시도

2. **품질 지표가 0%인 경우**
   - 더 구체적인 질문 입력
   - 키워드가 포함된 질문 시도

3. **응답이 생성되지 않는 경우**
   - API 키 설정 확인
   - 네트워크 연결 상태 확인

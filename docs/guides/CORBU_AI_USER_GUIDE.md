# CORBU AI 사용자 가이드

## 🎯 CORBU AI 소개

CORBU AI는 지능형 메시지 생성 플랫폼으로, 실시간 학습을 통해 사용자의 패턴을 자동으로 학습하고 개선하는 혁신적인 AI 시스템입니다.

### 🌟 주요 특징

- **실시간 학습**: 대화를 통해 지속적으로 개선
- **패턴 인식**: 사용자 선호도를 자동으로 학습
- **개선 제안**: 구체적인 품질 향상 방안 제시
- **학습 점수**: 각 응답의 학습 효과를 수치화
- **영향도 분석**: 각 인사이트의 중요도를 평가

## 🚀 시작하기

### 1. 시스템 접속

```
브라우저에서 http://localhost:3000 접속
```

### 2. 메인 화면 구성

- **헤더 영역**: 시스템 제목과 기능 버튼들
- **메시지 영역**: 실시간 채팅 인터페이스
- **입력 영역**: 메시지 입력 및 전송
- **사이드 패널**: 학습, 분석, 템플릿, 가이드 패널

## 📝 기본 사용법

### 1. 메시지 생성하기

#### 단계별 가이드

1. **메시지 입력**: 하단 입력창에 메시지를 입력합니다
2. **지침 선택**: 가이드 패널에서 적용할 지침을 선택합니다
3. **설정 조정**: 톤, 스타일, 길이를 설정합니다
4. **전송**: "전송" 버튼을 클릭하거나 Enter를 누릅니다
5. **결과 확인**: AI가 생성한 메시지와 신뢰도를 확인합니다

#### 예시

```
사용자 입력: "고객이 제품에 불만을 가지고 있습니다. 어떻게 응답해야 할까요?"

AI 응답: "고객님의 불편함을 충분히 이해합니다. 즉시 조치하여 해결해드리겠습니다."
신뢰도: 85%
학습 점수: 78%
```

### 2. 학습 인사이트 확인하기

#### 학습 패널 열기

1. 헤더의 "학습" 버튼 클릭
2. 학습 인사이트 목록 확인
3. 영향도별 분류 확인 (High/Medium/Low)
4. 신뢰도 표시 확인

#### 인사이트 유형

- **패턴 발견**: 사용자 선호도 패턴
- **개선 제안**: 응답 품질 향상 방안
- **제안사항**: 새로운 기능 제안

### 3. 템플릿 사용하기

#### 템플릿 패널 열기

1. 헤더의 "템플릿" 버튼 클릭
2. 템플릿 목록 확인
3. 원하는 템플릿 선택
4. "사용" 버튼 클릭

#### 템플릿 정보

- **성공률**: 템플릿의 성공 비율
- **평점**: 사용자 피드백 평점
- **사용 횟수**: 템플릿 사용 통계

### 4. 분석 대시보드 확인하기

#### 분석 패널 열기

1. 헤더의 "분석" 버튼 클릭
2. 종합 통계 확인
3. 성능 지표 확인
4. 사용 패턴 분석

#### 주요 지표

- **총 메시지 수**: 생성된 총 메시지 수
- **평균 신뢰도**: 전체 메시지의 평균 신뢰도
- **응답 시간**: 평균 응답 시간
- **학습 진행률**: 시스템 학습 진행 상황
- **개선률**: 시스템 성능 향상률

## 🎛️ 고급 기능

### 1. 가이드 패널 설정

#### 응답 스타일 설정

- **톤**: 공식적, 친근한, 전문적
- **스타일**: 정보 제공, 설득적, 공감적, 분석적
- **길이**: 짧음, 보통, 길음

#### 지침 선택

- **의사소통**: 공식적 의사소통 지침
- **안전**: 안전 관련 응대
- **기술**: 기술적 문제 해결
- **감정 지원**: 감정적 지원
- **정보 제공**: 정보 제공
- **학습**: 실시간 학습 적용

### 2. 사용자 정의 템플릿

#### 템플릿 저장하기

1. 생성된 메시지에서 "Save as Template" 버튼 클릭
2. 템플릿 이름 입력
3. 템플릿이 저장되고 목록에 추가됨

#### 템플릿 관리

- **성공률 추적**: 템플릿 사용 성공률
- **사용자 피드백**: 평점 시스템
- **자동 개선**: 사용 패턴에 따른 최적화

### 3. 실시간 학습 모니터링

#### 학습 점수 확인

- 각 메시지의 학습 점수 표시
- 학습 효과를 백분율로 확인
- 개선 제안 확인

#### 개선 제안 활용

- 구체적인 품질 향상 방안
- 지침 활용 제안
- 응답 스타일 개선 방안

## 🔧 문제 해결

### 1. 일반적인 문제

#### 메시지가 생성되지 않을 때

1. 인터넷 연결 확인
2. 브라우저 새로고침
3. 입력 메시지 길이 확인
4. 지침 선택 상태 확인

#### 학습 인사이트가 표시되지 않을 때

1. 충분한 메시지 교환 후 확인
2. 학습 패널 새로고침
3. 시스템 재시작

#### 템플릿이 저장되지 않을 때

1. 템플릿 이름 입력 확인
2. 메시지 내용 확인
3. 저장 버튼 재클릭

### 2. 성능 최적화

#### 빠른 응답을 위한 팁

1. 간결한 메시지 입력
2. 적절한 지침 선택
3. 브라우저 캐시 정리
4. 불필요한 탭 닫기

#### 메모리 사용량 최적화

1. 주기적인 브라우저 새로고침
2. 오래된 대화 기록 정리
3. 불필요한 패널 닫기

## 📊 성능 지표 이해

### 1. 신뢰도 (Confidence)

- **85% 이상**: 매우 높은 신뢰도
- **70-84%**: 높은 신뢰도
- **50-69%**: 보통 신뢰도
- **50% 미만**: 낮은 신뢰도

### 2. 학습 점수 (Learning Score)

- **80% 이상**: 우수한 학습 효과
- **60-79%**: 좋은 학습 효과
- **40-59%**: 보통 학습 효과
- **40% 미만**: 낮은 학습 효과

### 3. 개선률 (Improvement Rate)

- **+10% 이상**: 뛰어난 개선
- **+5-9%**: 좋은 개선
- **+1-4%**: 보통 개선
- **0% 이하**: 개선 필요

## 🚀 고급 사용법

### 1. 효율적인 지침 활용

#### 상황별 지침 선택

- **고객 응대**: 의사소통 + 감정 지원
- **기술 지원**: 기술 + 정보 제공
- **안전 사고**: 안전 + 의사소통
- **일반 문의**: 정보 제공 + 의사소통

#### 우선순위 활용

- **High**: 중요한 상황에서 우선 적용
- **Medium**: 일반적인 상황에서 활용
- **Low**: 참고용으로 활용

### 2. 학습 최적화

#### 패턴 학습 촉진

1. 일관된 스타일 사용
2. 정기적인 피드백 제공
3. 다양한 상황 시도
4. 개선 제안 활용

#### 인사이트 활용

1. 패턴 발견 확인
2. 개선 제안 적용
3. 영향도 높은 인사이트 우선 적용
4. 정기적인 분석 확인

### 3. 템플릿 최적화

#### 성공률 높은 템플릿 활용

1. 성공률 90% 이상 템플릿 우선 사용
2. 평점 4.5 이상 템플릿 활용
3. 사용 횟수 많은 템플릿 참고

#### 템플릿 개선

1. 실패한 템플릿 분석
2. 개선 제안 적용
3. 새로운 템플릿 생성
4. 정기적인 템플릿 업데이트

## 🎯 모범 사례

### 1. 효과적인 메시지 생성

#### 좋은 예시

```
입력: "고객이 제품 결함을 신고했습니다."
지침: 안전 + 의사소통 + 감정 지원
설정: 공식적 + 공감적 + 보통
결과: "고객님의 불편함을 충분히 이해합니다. 즉시 조치하여 안전하게 해결해드리겠습니다."
```

#### 피해야 할 예시

```
입력: "고객이 제품 결함을 신고했습니다."
지침: 없음
설정: 기본값
결과: "알겠습니다." (너무 간단하고 공감적이지 않음)
```

### 2. 학습 최적화

#### 좋은 예시

- 다양한 상황 시도
- 일관된 스타일 유지
- 정기적인 분석 확인
- 개선 제안 적극 활용

#### 피해야 할 예시

- 단조로운 패턴만 사용
- 분석 결과 무시
- 개선 제안 무시
- 학습 점수 무시

# 🎯 궁극의 미디어 지식 활용 시스템 가이드

## 📋 개요

ChatGPT-5 수준의 미디어 이해 및 지식 추출 시스템입니다. 다양한 미디어 파일을 업로드하면 AI가 분석하여 설득력 있는 콘텐츠로 변환해줍니다.

## 🚀 주요 기능

### 1. **멀티모달 미디어 분석**
- **이미지**: OCR 텍스트 추출, 객체 감지, 이미지 품질 분석
- **비디오**: 프레임 분석, 오디오 추출, 장면 인식
- **오디오**: 음성 인식, 감정 분석, 언어 감지
- **문서**: PDF, Word, Excel, PowerPoint 텍스트 추출
- **스프레드시트**: 데이터 구조 분석, 통계 추출

### 2. **지능형 지식 추출**
- **엔터티 인식**: 사람, 조직, 장소, 날짜 등 자동 추출
- **관계 분석**: 엔터티 간 관계 및 연결성 파악
- **인사이트 생성**: 핵심 주제 및 중요 정보 도출
- **신뢰도 평가**: 추출된 지식의 품질 및 정확도 측정

### 3. **설득력 있는 콘텐츠 생성**
- **논리적 구조**: 도입부, 본론, 결론의 체계적 구성
- **감정적 호소**: 공감, 동정, 희망 등 감정 요소 활용
- **증거 기반**: 통계, 사례, 연구 결과 등 객관적 증거 제시
- **설득 기법**: Ethos(신뢰성), Pathos(감정), Logos(논리) 적용

### 4. **실시간 학습 및 적응**
- **지식 베이스**: 프로젝트별 지식 축적 및 관리
- **학습 히스토리**: 분석 과정 및 결과 추적
- **성능 최적화**: 사용 패턴 기반 시스템 개선
- **개인화**: 사용자별 맞춤형 분석 및 응답

## 🛠️ 설치 및 실행

### 0. **선택 의존성 (기능별)**

| 기능 | 패키지 | 비고 |
|------|--------|------|
| PPTX 텍스트 추출 | `python-pptx` | `pip install python-pptx` |
| XLSX 텍스트 추출 | `openpyxl` | `pip install openpyxl` |
| 오디오→텍스트 | `openai-whisper` | 용량 큼, torch 의존성 |
| 비디오 오디오 추출 | ffmpeg | 시스템 설치: `brew install ffmpeg` |

미설치 시 해당 형식은 기본 placeholder로 동작합니다. `backend/requirements-optional.txt` 참고.

### 1. **시스템 시작**

```bash
# 궁극의 미디어 지식 시스템 시작
./start_ultimate_media_system.sh
```

### 2. **프론트엔드 실행**

```bash
# React 개발 서버 시작
npm start
```

### 3. **시스템 상태 확인**

```bash
# 백엔드 API 상태 확인
curl http://localhost:5002/api/v1/health
```

## 📖 사용 방법

### 1. **파일 업로드**

1. 웹 인터페이스에서 파일 업로드 영역 클릭
2. 분석할 미디어 파일 선택 (다중 선택 가능)
3. 지원 형식:
   - **이미지**: JPG, PNG, GIF, BMP, TIFF, WebP
   - **비디오**: MP4, AVI, MOV, WMV, FLV, MKV, WebM
   - **오디오**: MP3, WAV, FLAC, AAC, OGG, M4A
   - **문서**: PDF, DOC, DOCX, TXT, RTF, ODT
   - **프레젠테이션**: PPT, PPTX
   - **스프레드시트**: XLS, XLSX, CSV

### 2. **분석 결과 확인**

업로드된 파일이 자동으로 분석되며, 다음 정보를 제공합니다:

- **📄 파일 정보**: 파일명, 크기, 타입, 분석 시간
- **🧠 추출된 지식**: 지식 타입, 신뢰도, 엔터티, 인사이트
- **💡 설득력 있는 콘텐츠**: 논리적 구조, 감정적 호소, 설득 기법
- **📋 지식 요약**: 핵심 내용 및 주요 발견사항
- **🎓 학습 인사이트**: 활용 방안 및 개선 제안

### 3. **지식 베이스 활용**

- **프로젝트별 관리**: 각 프로젝트의 지식 베이스 독립 관리
- **지식 축적**: 분석된 파일들의 지식이 자동으로 축적
- **검색 및 활용**: 과거 분석 결과를 새로운 작업에 활용

## 🔧 고급 기능

### 1. **API 직접 사용**

```bash
# 미디어 파일 분석
curl -X POST "http://localhost:5002/api/v1/analyze-media" \
  -F "file=@your_file.jpg" \
  -F "project_id=your_project_id"

# 지식 베이스 조회
curl "http://localhost:5002/api/v1/knowledge-base/your_project_id"

# 학습 히스토리 조회
curl "http://localhost:5002/api/v1/learning-history"
```

### 2. **프로그래밍 방식 사용**

```typescript
import UltimateMediaKnowledgeService from './services/ultimateMediaKnowledgeService';

const mediaService = UltimateMediaKnowledgeService.getInstance();

// 파일 분석
const result = await mediaService.analyzeMediaFile(file, projectId);

// 지식 베이스 조회
const knowledgeBase = await mediaService.getKnowledgeBase(projectId);

// 시스템 상태 확인
const health = await mediaService.checkSystemHealth();
```

## 🔧 문제 해결

### 1. **일반적인 문제**

**Q: 파일 업로드가 실패합니다.**
A: 파일 크기와 형식을 확인하고, 네트워크 연결 상태를 점검하세요.

**Q: 분석 결과가 부정확합니다.**
A: 파일 품질을 확인하고, 더 명확한 이미지나 문서를 사용해보세요.

**Q: 시스템이 느립니다.**
A: 동시 분석 파일 수를 줄이고, 서버 리소스를 확인하세요.

### 2. **기술적 문제**

**Q: OCR이 제대로 작동하지 않습니다.**
A: 이미지 품질을 개선하고, 텍스트가 명확하게 보이는지 확인하세요.

**Q: 음성 인식이 부정확합니다.**
A: 오디오 품질을 개선하고, 배경 소음을 줄여보세요.

**Q: 시스템이 응답하지 않습니다.**
A: 서버 상태를 확인하고, 필요시 재시작하세요.

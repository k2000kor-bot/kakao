## 🎯 테스트 시나리오

### 1. 🤖 지능형 응답 생성 테스트

다음 질문들을 입력하여 지능형 응답 엔진의 기능을 확인하세요:

#### 🔍 테스트 질문 0: 기본 질문 이해
```
안녕하세요, 간단한 질문을 해도 될까요?
```

**예상 분석 결과:**
- 질문 유형: factual (사실 확인)
- 복잡도: 1-2/10
- 의도: 정보 요청 + 정중한 표현

### 2. 복잡한 질문 분해 테스트

다음 질문들을 입력하여 고도화된 분석 기능을 확인하세요:

#### 🔍 테스트 질문 1: 다중 요구사항 질문
```
원베일리 아파트 하자 문제에 대해 최근 뉴스를 검색하고, 주민들의 댓글 반응을 분석해서 정리해주고, 법적 대응 방안도 함께 제시해줘
```

**예상 분석 결과:**
- 질문 구성 요소: 3개 (뉴스 검색, 댓글 분석, 법적 조언)
- 복잡도: 8-9/10
- 의도: 정보 수집 + 분석 + 조언 요청

#### 🔍 테스트 질문 2: 암시적 요구사항 포함
```
AI 개발 프로젝트를 시작하려고 하는데, 프론트엔드는 React로 하고 백엔드는 뭐가 좋을지 추천해주고, 팀 구성은 어떻게 해야 할지, 그리고 예산은 대략 얼마나 필요한지 알고 싶어
```

**예상 분석 결과:**
- 질문 구성 요소: 4개 (기술 스택, 팀 구성, 예산, 프로젝트 계획)
- 복잡도: 7-8/10
- 의도: 기술 조언 + 인력 계획 + 비용 추정

#### 🔍 테스트 질문 3: 논리적 추론 요구
```
최근 부동산 시장이 불안정한데, 이게 IT 스타트업 투자에도 영향을 미칠까? 그리고 만약 영향이 있다면 우리가 어떤 전략을 취해야 할지 분석해줘
```

**예상 분석 결과:**
- 질문 구성 요소: 2개 (시장 분석, 전략 수립)
- 복잡도: 9/10
- 의도: 인과관계 분석 + 전략적 조언

### 2. 🤖 지능형 응답 분석 패널 확인

질문을 입력한 후 다음 단계를 따라하세요:

1. **🤖 지능형 응답 분석 버튼 클릭**
   - 헤더 우측의 로봇 아이콘(🤖) 클릭
   - 지능형 분석 진행 상태 확인

2. **💡 고도화된 질문 분석 버튼 클릭**
   - 헤더 우측의 전구 아이콘(💡) 클릭
   - 실시간 분석 진행 상태 확인

2. **📋 질문 구성 요소 패널 확인**
   - 각 구성 요소의 타입 (primary, secondary, implicit)
   - 우선순위 점수 (1-10)
   - 복잡도 및 범위 분석

3. **🤖 지능형 응답 분석 패널 확인**
   - 질문 컨텍스트 (유형, 복잡도, 도메인, 의도)
   - 응답 품질 지표 (관련성, 완성도, 정확성, 명확성, 유용성)
   - 생성된 응답 내용 및 메타데이터
   - 추천 후속 질문 및 관련 주제

3. **🎯 응답 전략 패널 확인**
   - 톤 (formal, casual, technical 등)
   - 깊이 (surface, detailed, comprehensive)
   - 상호작용 요소 (명확화 질문 등)

4. **🧠 다층적 분석 결과 확인**
   - 표면 분석: 명시적 의도, 직접 질문
   - 심층 분석: 감정 맥락, 암시적 요구
   - 메타 분석: 인지 부하, 질문 전략

5. **📚 통합 지식 분석 확인**
   - 신뢰도 점수 및 진행바
   - 지원/반박 증거 개수
   - 식별된 지식 공백

### 3. 자동 기능 활성화 테스트

#### 🏢 원베일리 관련 자동 분석
```
원베일리 하자 관련해서 댓글 정리해줘 기사 댓글을 검색해줘
```

**예상 동작:**
- 뉴스 검색 패널 자동 활성화
- 키워드 기반 자동 응답 생성
- 관련 정보 및 출처 표시

### 4. NLP 분석 결과 확인

각 질문 후 AI 응답에서 다음 섹션들을 확인하세요:

#### 📊 NLP 분석 결과
- 감정 분석 (긍정적/부정적/중립적)
- 주요 키워드 추출
- 관련 주제 식별
- 자동 활성화된 기능들

#### 🔍 고도화된 질문 분석
- 질문 복잡도 점수
- 구성 요소 개수 및 상세 정보
- 예상 응답 길이
- 필요 역량 목록

#### 🤖 고급 AI 분석
- 신뢰도 점수
- 학습 점수
- 적응 수준
- 다음 액션 제안

### 5. 성능 및 품질 확인

#### 응답 품질 지표
- 각 메시지 하단의 품질 점수 확인
- 응답 시간 및 토큰 사용량 확인
- 신뢰도 및 도움도 점수 확인

#### 실시간 분석 상태
- 분석 진행 중 애니메이션 확인
- 각 패널의 로딩 상태 확인
- 오류 발생 시 적절한 에러 메시지 표시

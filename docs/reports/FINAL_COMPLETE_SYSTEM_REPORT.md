## **📋 사용 방법**

### **1. 시스템 시작**
```bash
# 백엔드 서버 시작
cd backend
source ../venv/bin/activate
python advanced_api_server.py

# 프론트엔드 서버 시작
npm start
```

### **2. 웹 접속**
- **프론트엔드**: http://localhost:3000
- **백엔드 API**: http://localhost:8000

### **3. API 사용 예시**
```bash
# AI 메시지 생성
curl -X POST "http://localhost:8000/api/v7/generate-gpt-message" \
  -H "Content-Type: application/json" \
  -d '{"target_message": "안녕하세요", "context": "일반 대화"}'

# 음성 인식 시작
curl -X POST "http://localhost:8000/api/v7/voice/start-recognition"

# 이미지 분석
curl -X POST "http://localhost:8000/api/v7/image/analyze-base64" \
  -H "Content-Type: application/json" \
  -d '{"image_data": "base64_encoded_image"}'
```

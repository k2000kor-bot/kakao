```python

```

#### **수학적 공식**

- **최종 점수**: `(키워드점수 + 컨텍스트점수 + 의미론점수) × 복잡도인수`
- **신뢰도**: `min(1.0, 정규화점수 / 100)`
- **복잡도 인수**: `min(1.5, 텍스트길이 / 1000)`

### **2. 통계학 기반 개체명 인식**

#### **알고리즘 구조**

```python
    # 4. 빈도 기반 점수 (TF-IDF 유사)
    # 5. 길이 기반 정규화
    # 6. 수학적 결합 (가중 평균)
    # 7. 신뢰도 계산 (베이지안 접근)
    # 8. 통계적 필터링 및 정렬
    # 9. 최종 정렬 및 중복 제거
```

#### **수학적 공식**

- **최종 점수**: `(기본점수×0.4 + 위치가중치×0.3 + 컨텍스트점수×0.2 + 빈도점수×0.1) × 길이인수`
- **빈도 점수**: `log(1 + 개체빈도) / log(총단어수 + 1)`
- **IQR 필터링**: `Q1 - 1.5×IQR ≤ 신뢰도 ≤ Q3 + 1.5×IQR`

### **6. 고급 수학적 분석**

#### **통계학적 분석**

- **기술통계량**: 평균, 중앙값, 표준편차

- **상관관계**: 단어 길이와 문장 길이의 상관계수

#### **확률론적 분석**

- **단어 확률**: `단어빈도 / 총단어수`
- **상호 정보량**: `log2(P(x,y) / (P(x) × P(y)))`
- **엔트로피**: `-Σ P(x) × log2(P(x))`

#### **선형대수 분석**

- **단어 벡터**: 26차원 문자 기반 벡터
- **코사인 유사도**: `A·B / (|A| × |B|)`
- **유사도 매트릭스**: 상위 10개 단어 간 유사도

#### **정보 이론 분석**

- **압축률**: `압축후크기 / 원본크기`
- **정보 밀도**: `엔트로피 / 텍스트길이`
- **Perplexity**: `2^엔트로피`

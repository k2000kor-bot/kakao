## 🛠️ 기술적 구현

### **프론트엔드 아키텍처**
```
src/components/MessageGuidanceSystem.tsx
├── 메인 컴포넌트
├── 상태 관리 (useState, useEffect)
├── 이벤트 핸들링
└── UI 렌더링
```

### **타입 시스템**
```typescript
interface Message {
  id: string;
  content: string;
  sender: string;
  timestamp: Date;
  type: 'user' | 'assistant' | 'system';
  metadata?: {
    confidence?: number;
    processingTime?: number;
    usedGuidelines?: string[];
    suggestions?: string[];
    template?: string;
    sentiment?: 'positive' | 'negative' | 'neutral';
    keywords?: string[];
  };
}
```

### **서비스 통합**
- ✅ `knowledgeService.ts` - 지식 베이스 관리
- ✅ `types/knowledge.ts` - 타입 정의
- ✅ `CompleteChatApp.tsx` - 메인 앱 통합
- ✅ `ConversationalInterface.tsx` - 대화형 인터페이스 연동

## 🔧 설치 및 실행

### **필요 조건**
```bash
Node.js >= 16.0.0
npm >= 8.0.0
```

### **설치 명령어**
```bash
cd kakao-frontend
npm install
npm start
```

### **접속 방법**
```
http://localhost:3000
```

### **사용 방법**
1. `/message_guide` 명령어 입력
2. 메시지 가이드 시스템 모달 열기
3. 원하는 템플릿 선택
4. 메시지 입력 (AI 자동완성 지원)
5. 지침 선택 및 스타일 설정
6. 메시지 생성 및 결과 확인

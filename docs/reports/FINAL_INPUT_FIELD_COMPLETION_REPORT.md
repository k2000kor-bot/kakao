## 📊 **기술적 구현**

### **1. 자동 줄바꿈 알고리즘**

#### **핵심 함수**

```typescript
const autoWrapText = (text: string, maxCharsPerLine: number = 34): string => {
  if (text.length <= maxCharsPerLine) return text;

  const lines: string[] = [];
  let currentLine = '';
  let charCount = 0;

  for (let i = 0; i < text.length; i++) {
    const char = text[i];

    // 줄바꿈 문자를 만나면 새 줄 시작
    if (char === '\n') {
      lines.push(currentLine);
      currentLine = '';
      charCount = 0;
      continue;
    }

    // 공백 문자를 만나면 줄바꿈 고려
    if (char === ' ' && charCount >= maxCharsPerLine) {
      lines.push(currentLine);
      currentLine = '';
      charCount = 0;
      continue;
    }

    currentLine += char;
    charCount++;

    // 최대 길이에 도달하면 강제 줄바꿈
    if (charCount >= maxCharsPerLine) {
      lines.push(currentLine);
      currentLine = '';
      charCount = 0;
    }
  }

  // 마지막 줄 추가
  if (currentLine) {
    lines.push(currentLine);
  }

  return lines.join('\n');
};
```

#### **알고리즘 특징**

- **조기 종료**: 34자 이하 텍스트는 즉시 반환
- **줄바꿈 존중**: 기존 줄바꿈 문자 유지
- **스마트 분할**: 공백 기반 자연스러운 줄바꿈
- **강제 분할**: 34자 초과 시 강제 줄바꿈

### **2. 실시간 적용 시스템**

#### **입력창 onChange 함수**

```typescript
onChange={(e) => {
  const value = e.target.value;
  // 자동 줄바꿈 적용
  const wrappedValue = autoWrapText(value, 34);
  setInputMessage(wrappedValue);
  // 자동 크기 조절
  if (textareaRef.current) {
    textareaRef.current.style.height = 'auto';
    textareaRef.current.style.height = `${Math.min(textareaRef.current.scrollHeight, 200)}px`;
  }
}}
```

## 🛠️ 기술적 구현

### **프론트엔드 아키텍처**

```
src/
├── components/
│   ├── MessageGuidanceSystem.tsx    # 메시지 가이드 시스템
│   ├── ConversationalInterface.tsx  # 대화형 인터페이스
│   ├── CompleteChatApp.tsx         # 메인 앱 컴포넌트
│   └── PerformanceMonitor.tsx       # 성능 모니터링
├── services/
│   ├── knowledgeService.ts          # 지식 베이스 서비스
│   └── advancedAIService.ts        # AI 서비스
├── types/
│   ├── knowledge.ts                 # 지식 관련 타입
│   └── chat.ts                      # 채팅 관련 타입
└── utils/
    └── apiHelper.ts                 # API 헬퍼
```

### **타입 시스템**

```typescript
interface Message {
  id: string;
  content: string;
  sender: string;
  timestamp: Date;
  type: 'user' | 'assistant' | 'system';
  metadata?: {
    confidence?: number;
    processingTime?: number;
    usedGuidelines?: string[];
    suggestions?: string[];
    template?: string;
    sentiment?: 'positive' | 'negative' | 'neutral';
    keywords?: string[];
  };
}
```

### **서비스 통합**

- ✅ `knowledgeService.ts` - 지식 베이스 관리
- ✅ `types/knowledge.ts` - 타입 정의
- ✅ `CompleteChatApp.tsx` - 메인 앱 통합
- ✅ `ConversationalInterface.tsx` - 대화형 인터페이스 연동

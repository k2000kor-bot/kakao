## 🔗 **통합된 API 엔드포인트**

### **기존 시스템 엔드포인트**
- `POST /api/message` - 일반 메시지 처리
- `POST /api/analysis` - 분석 요청 처리
- `POST /api/guidance` - 가이드 생성
- `POST /api/file` - 파일 처리
- `GET /api/systems/status` - 시스템 상태 확인
- `GET /api/project/{project_id}` - 프로젝트 정보
- `GET /api/files` - 파일 목록
- `POST /api/upload` - 파일 업로드

### **궁극의 통합 응답 시스템 엔드포인트**
- `POST /api/ultimate/process` - 궁극 응답 처리
- `GET /api/ultimate/status` - 궁극 시스템 상태
- `GET /api/ultimate/health` - 헬스 체크
- `GET /api/ultimate/capabilities` - 시스템 능력 정보
- `GET /api/ultimate/stats` - 통계 정보

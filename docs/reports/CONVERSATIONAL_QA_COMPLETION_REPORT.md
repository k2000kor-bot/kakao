## 🔧 API 엔드포인트

### 대화형 QA API

- **URL**: `POST /api/conversational/qa`
- **기능**: 질문 분석 및 답변 생성
- **입력**: 질문, 컨텍스트
- **출력**: 구조화된 답변 및 분석 결과

### 지식 베이스 API

- **URL**: `POST /api/conversational/knowledge`
- **기능**: 지식 베이스에 정보 추가
- **입력**: 주제, 내용, 소스 정보
- **출력**: 추가 성공/실패 결과

### 응답 구조

```json
{
  "success": true,
  "analysis_type": "conversational_qa",
  "result": {
    "question": "질문 내용",
    "answer": "생성된 답변",
    "confidence": 0.95,
    "question_analysis": {
      "question_type": "factual",
      "keywords": ["샘플 프로젝트", "재개발"],
```

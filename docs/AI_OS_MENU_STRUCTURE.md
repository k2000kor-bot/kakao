# AI OS 메뉴 구조 (ChatGPT 전체 UI 재설계 관점)

ChatGPT 스타일 전체 UI를 **AI OS** 관점에서 재구성한 메뉴 구조입니다.  
현재 프로젝트의 **AI Workspace Minimal UI**와 같은 원칙(최소 노출 + 생성형 기능)을 전체 화면에 적용한 확장안입니다.

---

## 1. AI OS란

- **기존**: 앱/메뉴 중심 — 사용자가 기능을 찾아 클릭.
- **AI OS**: 명령/대화 중심 — 사용자가 원하는 것을 말하면, AI가 기능을 실행하고 결과를 보여줌.
- **메뉴 역할**: 진입점·컨텍스트(프로젝트·대화·계정) 제공. 세부 기능은 대부분 “요청 시 생성”.

---

## 2. 전체 화면 영역 (재설계)

```
┌─────────────────────────────────────────────────────────────────┐
│  글로벌 헤더 (최소)                                              │
│  [로고] [통합 검색 또는 대화 진입] [알림] [사용자]                 │
└─────────────────────────────────────────────────────────────────┘
┌──────────────┬──────────────────────────────────────────────────┐
│  좌측 패널    │  메인 영역                                        │
│  (4개 영역)   │  - 대화 스레드 또는 검색/도구 결과                  │
│              │  - 프로젝트 대시(선택 시)                          │
│  [1] 검색    │  - 설정/프로필(선택 시)                            │
│  + 새대화   │                                                    │
│  [2] 프로젝트│  하단: 입력창 (공통)                               │
│  [3] 최근   │  "메시지 또는 명령 입력"                            │
│    대화     │                                                    │
│  [4] 사용자  │                                                    │
└──────────────┴──────────────────────────────────────────────────┘
```

- **좌측**: 현재 구현한 4개 영역과 동일 (검색+새대화 / 프로젝트 / 최근 대화 / 사용자).
- **메인**: 선택된 컨텍스트(대화·프로젝트·설정)에 따라 하나의 캔버스. 별도 “기능 메뉴” 탭을 두지 않고, 입력창이 공통 명령 진입점.
- **모델 선택**: 화면 어디에도 두지 않고, 내부 라우팅만 사용.

---

## 3. ChatGPT 대비 변경 요약

| 항목 | ChatGPT 스타일 | AI OS 메뉴 구조 |
|------|-----------------|-----------------|
| 새 대화/새 프로젝트 | 여러 버튼·메뉴 | 상단 검색/새대화 + “프로젝트 만들어줘” 등 프롬프트 |
| 검색 | 대화 검색 메뉴 | 통합 검색 한 줄 + “OO 관련 대화 찾아줘” |
| 설정/플러그인/모델 | 설정 화면·드롭다운 | 사용자 영역(프로필·설정 링크) + 모델은 내부 라우팅 |
| 기능 노출 | 사이드바·상단 탭 다수 | 4개 영역만 고정, 나머지 생성형 |

---

## 4. 자이그랩스·카톡 여론 분석에 적용 시

- **동일 4개 영역** 유지.
- **프로젝트** = “여론 분석 프로젝트”, “채널별 분석” 등.
- **생성형 기능 예**: “이 채널 지난달 요약”, “감성 추이 보고서”, “키워드 트렌드 분석” → 의도 감지 후 해당 파이프라인/도구 실행.

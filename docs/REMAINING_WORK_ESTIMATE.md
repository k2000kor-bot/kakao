## 2. 남은 작업 구간별 예상

### 2.1 배포 전 필수 — **0% 남음**

- deploy:check(verify:completion + build) 통과 시 배포 가능.
- 추가로 **반드시** 해야 할 작업은 없음.

---

### 2.2 단기 (선택, 1~2주) — **대략 10~15%**

| 영역 | 내용 | 예상 공수 |
|------|------|------------|
| 성능 | Lighthouse Perf 90 유지 점검, LCP 등 재측정 | 0.5~1일 |
| UX | 로딩·에러·토스트 일관화 점검, 온보딩 문구 보강 | 0.5~1일 |
| 접근성 | axe-core·스크린 리더 검증, 키보드 플로우 보강 | 0.5~1일 |
| PWA | manifest·sw 동작 검증·문서화 (이미 구현됨, 검증 위주) | 0.5일 |
| 웹 검색 | DuckDuckGo 등 실 API 연동 또는 문서화 정리 | 0.5~1일 |
| E2E | 로그인·노트북 전체 플로우 등 1~2개 추가 | 1~2일 |
| 테스트 | 미커버 구간(AdvancedFeaturesPanel·qwenTts 등) 테스트 추가 | 1~2일 |

**합계**: 약 **5~8일** (1인 기준, 선택 사항만).

### 2.4 장기 (확장 범위, BACKLOG 테이블) — **대략 50%+**

BACKLOG §확장 범위 테이블에 있는 항목들(P2~P5)입니다.  
전부 하면 “완성도 100%”에 가깝지만, **우선순위가 낮거나 나중 단계**입니다.

| 구간 | 예시 | 예상 |
|------|------|------|
| P2~P3 | 성능·UX·접근성·PWA·웹검색·NotebookLM·분석·문서화 등 | 위 단기·중기와 겹침, 나머지 세부 |
| P4 | CI/CD·오프라인·통합 API·협업·보안·알림·데이터·검색·템플릿·피드백·API 관리·관찰성·AI 품질 등 (구독 제외) | 항목당 1~5일, 총 수주~한 달 |
| P5 | 에이전트·개발자 생태계·멀티테넌시·엔터프라이즈·교육·A/B·게이미피케이션·엣지 AI·업종별·멀티에이전트 등 | 항목당 수일~수주, 총 수개월 규모 |

**정리**:  
- **“지금 남은 부분”**만 보면 → **배포 필수는 0%**, **선택 품질·확장이 약 10~30%** (단기·중기).  
- **확장 범위 전체**를 100%로 보면 → **이미 구현·검증된 핵심이 약 50%**, **나머지 50%+**는 위 P4·P5 항목들.

## 3. 한 줄 요약

- **배포하려면**: 남은 필수 작업 **0%** — `deploy:check` 통과하면 됨.  
- **품질·사용성만 더 챙기려면**: 단기(1~2주) 선택 작업 **약 10~15%** (성능·UX·a11y·PWA·E2E·테스트 등).  
- **확장 비전까지 쌓으려면**: 중기(2~4주) **약 20~30%** + 장기(수개월) **50%+**.

원하시는 목표(배포만 / 품질 강화 / 확장 기능)에 따라 “남은 부분” 비율이 위와 같이 달라진다고 보시면 됩니다.

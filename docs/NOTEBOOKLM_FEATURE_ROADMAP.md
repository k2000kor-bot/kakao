## 2. 순차 개발 단계 (Phase)

### Phase 1: 핵심 완료 ✅
- 프로젝트(노트북) CRUD, 노트북 컨텍스트 저장·로드  
- 대화 시 프로젝트 지식 그라운딩  
- 소스 추가·삭제·목록, 소스 N개 표시  
- 스튜디오: 보고서, 학습 가이드, 퀴즈, 요약, 플래시카드  
- AI 검증 안내 문구  
- **이미 구현된 범위.**

### Phase 2: 스튜디오·소스 확장 (우선)
1. **스튜디오 유형 확장** ✅  
   동영상 개요, 마인드맵, 인포그래픽, 슬라이드, 데이터 표용 프롬프트 추가 완료 → 동일 API로 생성 가능.
2. **스튜디오 출력 저장** ✅  
   생성된 항목을 프로젝트별로 목록 저장·조회 API 및 UI (생성 이력 표시). NotebookLLM에 스튜디오 패널 추가됨.
3. **소스 타입 확장**  
   파일 업로드(PDF 등) 또는 URL 입력으로 소스 추가 시, 텍스트 추출 후 기존 소스 추가 플로우에 연결.
4. **추천 질문** ✅  
   대화 시작/소스 로드 후, 소스 기반 추천 질문 3~5개 생성·노출. ChatGPTInterface 빈 대화 시 getNotebookSuggestedQuestions 호출·추천 질문 칩 표시.

### Phase 3: 연구·분석
1. **웹 검색 / Fast Research** ✅  
   쿼리 입력 시 웹 검색 결과를 요약해 “소스 후보”로 표시, 선택 시 노트북 소스로 추가.
2. **Deep Research** ✅  
   심층 보고서 생성·새 소스 제안 (DeepResearchModal).
3. **분석 버튼** ✅  
   현재 노트북 소스 요약·키워드·분석 결과 한 페이지. NotebookLLM에 분석 버튼 추가 (소스 수·단어 수·문자 수·키워드·미리보기).
4. **스튜디오 메모** ✅  
   스튜디오 패널에 메모 추가·저장 (프로젝트별 localStorage, blur 시 자동 저장).

### Phase 4: 공유·설정·연동
1. **공유** ✅  
   노트북 읽기 전용 링크 생성·비공개 설정 (ProjectShareDialog, projectShareService).
2. **설정** ✅  
   노트북 이름·설명·태그·가이드라인 편집 (ProjectEditModal, ChatGPTInterface ⚙️ 버튼).
3. **Drive 연동** 🔶 스텁 (선택)  
   Google Drive에서 파일 선택 후 노트북 소스로 가져오기. 준비 중 모달·data-testid·테스트 완료.

### Phase 5: 대시보드·프로필
1. **전체 / 내 노트북 / 추천 노트북** ✅  
   탭별 노트북 목록, 정렬(최신순·이름순·소스순).
2. **추천 노트북** ✅  
   학습 노트·연구 노트·업무 노트 템플릿 카드, 클릭 시 해당 이름으로 노트북 생성.
3. **PRO·사용자 프로필**  
   구독 상태 표시, 프로필 영역. (UI 스텁: 사이드바 하단 PRO 배지)

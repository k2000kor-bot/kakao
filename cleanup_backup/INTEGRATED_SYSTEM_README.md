# 🚀 CORBU AI 통합 시스템

## 📋 개요

CORBU AI 통합 시스템은 모든 개발된 기능들을 하나로 통합한 완전한 AI 플랫폼입니다. ChatGPT 스타일의 질문-답변 인터페이스를 제공하며, 고급 AI 분석, 파일 처리, 프로젝트 관리 등의 기능을 포함합니다.

## ✨ 주요 기능

### 🤖 **통합 AI 시스템**
- **4가지 AI 모델**: Ultimate, Quantum, Advanced, Standard
- **실시간 감정 분석**: 96.5% 정확도
- **다층적 분석**: 텍스트, 감정, 데이터, 품질, 성능, 보안 통합 분석
- **오프라인 모드**: API 연결 실패 시 자동 폴백

### 💬 **ChatGPT 스타일 인터페이스**
- **직관적인 대화**: 자연스러운 질문-답변
- **실시간 응답**: 스트리밍 메시지 처리
- **메타데이터 표시**: 모델, 처리시간, 신뢰도 정보
- **키보드 단축키**: Ctrl+K (포커스), Ctrl+S (저장), Ctrl+N (새 프로젝트)

### 📁 **고급 파일 관리**
- **드래그 앤 드롭**: 파일을 쉽게 업로드
- **실시간 진행률**: 업로드 및 분석 진행상황 표시
- **AI 파일 분석**: 자동 텍스트 추출 및 키워드 분석
- **다중 파일 지원**: 여러 파일 동시 처리

### 📊 **프로젝트 관리**
- **프로젝트 생성**: 무제한 프로젝트 생성
- **파일 조직화**: 프로젝트별 파일 관리
- **대화 저장**: 로컬 스토리지에 대화 저장
- **상태 추적**: 프로젝트별 진행상황 추적

### 🎨 **사용자 경험**
- **다크/라이트 모드**: 테마 전환 지원
- **반응형 디자인**: 모든 디바이스 최적화
- **사이드바**: 접을 수 있는 사이드바
- **실시간 상태**: 시스템 상태 실시간 모니터링

## 🛠️ 기술 스택

### **프론트엔드**
- **React 19.1.0**: 최신 React 버전
- **TypeScript**: 타입 안전성
- **Tailwind CSS**: 유틸리티 CSS
- **Lucide React**: 아이콘 라이브러리
- **Material-UI**: 컴포넌트 라이브러리

### **백엔드**
- **Python 3.8+**: 메인 언어
- **FastAPI**: 고성능 API 프레임워크
- **Uvicorn**: ASGI 서버
- **Pydantic**: 데이터 검증
- **WebSocket**: 실시간 통신

### **통합 기능**
- **감정 분석 엔진**: 한국어 특화 감정 분석
- **데이터 분석 시스템**: 실시간 데이터 처리
- **품질 보증 시스템**: 자동화된 테스트
- **성능 최적화**: 동적 리소스 관리
- **보안 시스템**: 다층 보안 구조

## 🚀 빠른 시작

### **1. 시스템 요구사항**
- Node.js 16.0+
- Python 3.8+
- npm 또는 yarn
- Git

### **2. 설치 및 실행**

```bash
# 저장소 클론
git clone <repository-url>
cd kakao-frontend

# 통합 시스템 시작
./start_integrated_system.sh
```

### **3. 접속**
- **프론트엔드**: http://localhost:3000
- **백엔드 API**: http://localhost:8000
- **API 문서**: http://localhost:8000/docs

## 📖 사용법

### **기본 대화**
1. 메시지 입력창에 질문을 입력
2. Enter 키 또는 전송 버튼 클릭
3. AI가 실시간으로 응답 생성

### **파일 업로드**
1. 파일을 드래그하여 업로드 영역에 드롭
2. 또는 클립 아이콘을 클릭하여 파일 선택
3. AI가 자동으로 파일 분석 수행

### **프로젝트 관리**
1. 사이드바에서 "새 프로젝트 시작" 클릭
2. 프로젝트별로 파일과 대화 관리
3. 프로젝트 정보는 사이드바에 표시

### **AI 모델 선택**
1. 사이드바 하단의 모델 선택 드롭다운 사용
2. 4가지 모델 중 선택:
   - **CORBU AI Ultimate**: 궁극의 통합 AI
   - **CORBU AI Quantum**: 양자 컴퓨팅 기반
   - **CORBU AI Advanced**: 고급 분석 AI
   - **CORBU AI Standard**: 표준 AI

## 🔧 고급 기능

### **키보드 단축키**
- `Ctrl+K`: 입력창 포커스

- **키워드 분석**: 주요 키워드 자동 추출
- **감정 분석**: 파일 내용의 감정 분석
- **신뢰도 점수**: 분석 결과의 신뢰도 표시

### **실시간 모니터링**
- **시스템 상태**: 백엔드 서버 상태 확인
- **처리 시간**: 각 요청의 처리 시간 표시
- **신뢰도 점수**: AI 응답의 신뢰도 표시
- **모델 정보**: 사용된 AI 모델 정보

## 🔍 API 엔드포인트

### **대화 API**
- `POST /api/chat`: 메시지 전송 및 AI 응답
- `GET /api/status`: 시스템 상태 조회
- `WebSocket /ws`: 실시간 통신

### **파일 API**
- `POST /api/upload`: 파일 업로드 및 분석
- `GET /api/analytics`: 분석 데이터 조회

## 🐛 문제 해결

### **일반적인 문제**

1. **포트 충돌**
   ```bash
   # 포트 사용 중인 프로세스 확인
   lsof -i :3000
   lsof -i :8000
   
   # 프로세스 종료
   kill -9 <PID>
   ```

2. **의존성 설치 오류**
   ```bash
   # Node.js 캐시 정리
   npm cache clean --force
   
   # Python 캐시 정리
   pip cache purge
   ```

3. **API 연결 실패**
   - 백엔드 서버가 실행 중인지 확인
   - 방화벽 설정 확인
   - 포트 8000이 열려있는지 확인

### **로그 확인**
```bash
# 백엔드 로그
tail -f logs/backend.log

# 프론트엔드 로그
npm start 2>&1 | tee logs/frontend.log
```

## 📋 프로젝트 개요

**CORBU AI**는 ChatGPT 스타일의 대화형 인터페이스를 통해 모든 AI 기능에 접근할 수 있는 **고도화된 통합 AI 플랫폼**입니다. 사용자는 자연스러운 대화를 통해 AI 분석, 최적화, 심리학, 학습, 비즈니스 워크플로우 등 다양한 AI 기능을 활용할 수 있으며, **복합 질문 분석 및 종합 답변 생성 시스템**을 통해 체계적이고 포괄적인 AI 서비스를 제공합니다. 프로젝트는 매번 달라질 수 있으며, 사용자가 원하는 어떤 주제든 자유롭게 설정하고 AI와 함께 작업할 수 있습니다.

---

## ✅ 완성된 주요 기능

### 🤖 **1. AI 기반 대화형 분석 시스템**

- **자연어 의도 인식**: 사용자 요청의 정확한 파악
- **컨텍스트 이해**: 대화 맥락을 고려한 응답 생성
- **실시간 분석**: 즉시 결과 제공
- **다중 분석 엔진**: 통합된 분석 파이프라인
- **감정 분석**: 텍스트 감정 및 톤 세밀 분석
- **의도 인식**: 사용자 요청의 정확한 파악

### ✍️ **2. 전문가 스타일 글쓰기 엔진**

- **논술가 (Essayist)**: 논리적이고 체계적인 에세이 작성
- **비평가 (Critic)**: 전문적인 비평 및 분석 글
- **선거평론가 (Election Critic)**: 정치적 사안에 대한 전문 분석
- **영화평론가 (Film Critic)**: 영화 및 문화 콘텐츠 비평
- **여론평론가 (Public Opinion Critic)**: 사회 여론 분석
- **정치평론가 (Political Critic)**: 정치적 사안 분석

### 🎭 **3. 고급 스타일 분석 및 복제 시스템**

- **스타일 DNA 분석**: 문체, 어조, 논리 구조 완전 분석
- **어조 복제**: 기존 텍스트 스타일을 새로운 주제에 정확히 적용
- **논리 구조 재현**: 원본의 논증 방식과 전개 패턴 모방
- **다중 계층 분석**: 어휘, 문법, 수사법 등 세밀한 분석

### 🏛️ **4. 정치적 성향별 글쓰기**

- **극우 (Extreme Right)**: 보수적 가치관 중심
- **보수 (Conservative)**: 전통적 보수 관점
- **중도우파 (Center Right)**: 온건 보수 입장
- **중도 (Center)**: 균형잡힌 중립적 시각
- **중도좌파 (Center Left)**: 온건 진보 관점
- **진보 (Progressive)**: 개혁적 진보 사상
- **극좌 (Extreme Left)**: 급진적 좌파 이념
- **강성 (Militant)**: 투쟁적이고 강경한 어조

### 📊 **5. 실시간 데이터 시각화 및 모니터링**

- **실시간 시스템 모니터링**: CPU, 메모리, 네트워크, 사용자 활동 등 실시간 성능 지표 시각화
- **고급 차트 및 그래프**: 성능 트렌드, 사용자 만족도, AI 모델 성능 비교 등 다양한 시각화 제공
- **동적 데이터 업데이트**: 3초마다 자동으로 업데이트되는 실시간 데이터

### 🏆 **6. 다중 AI 모델 선택 및 성능 최적화**

- **5가지 AI 모델 지원**: GPT-4, Claude 3, Gemini Pro, GPT-3.5, 커스텀 모델
- **모델별 특성 반영**: 각 AI 모델의 고유한 특성을 반영한 맞춤형 응답 생성
- **성능 비교 시각화**: 원형 차트를 통한 직관적인 AI 모델 성능 비교

### 👥 **7. 실시간 협업 및 팀워크 시스템**

- **실시간 협업 대화**: 팀원들과의 실시간 소통 및 아이디어 공유
- **협업자 상태 모니터링**: 온라인/오프라인 상태 및 역할별 정보 표시
- **화상 통화**: 실시간 화상 회의
- **화면 공유**: 작업 화면 공유
- **화이트보드**: 협업을 위한 공유 화이트보드

### 🎨 **8. 고급 콘텐츠 생성 시스템**

**포맷 (5가지):**

- 일반 글, 요약문, 카드뉴스, 반박글, 분석문

**톤 (5가지):**

- 전문적, 친근한, 격식있는, 창의적, 캐주얼

**채널별 최적화:**

- 블로그, Instagram, YouTube, 뉴스레터

## 🛠️ 기술 스택

### **프론트엔드**

- **React 18** + **TypeScript**
- **Material-UI (MUI)** - UI 컴포넌트
- **Redux Toolkit** - 상태 관리
- **Framer Motion** - 애니메이션
- **WebSocket** - 실시간 통신

### **백엔드**

- **Python Flask** - 웹 프레임워크
- **고급 AI 분석 엔진** - 20개 AI 서비스
- **실시간 데이터 처리** - 성능 모니터링
- **RESTful API** - API 통신

### **주요 컴포넌트**

- `ChatGPTMainInterface` - 메인 인터페이스
- `ChatGPT5CompleteInterface` - 완전한 ChatGPT 스타일 UI
- `FileAnalysisChatSystem` - 파일 분석 시스템
- `AICodeGenerator` - AI 코드 생성기
- `RealTimeConversationAnalyzer` - 실시간 대화 분석

## 🎯 사용자 체험 가이드

### **1단계: 브라우저 접속**

```
http://localhost:3000
```

### **2단계: 새 프로젝트 생성**

1. **"+" 버튼** 클릭
2. **프로젝트 이름** 입력 (예: "나만의 AI 프로젝트", "비즈니스 분석", "학습 계획" 등)
3. **카테고리 선택**:
   - 💰 **투자**: 투자 분석 및 전략
   - 🎓 **숙제**: 학습 도우미
   - ✍️ **글쓰기**: 창작 및 문서 작성
   - ❤️ **건강**: 건강 관리
   - ✈️ **여행**: 여행 계획

### **3단계: AI와 대화**

```
예시 메시지들:
- "안녕하세요, CORBU AI입니다!"
- "내 프로젝트에 대해 분석해주세요"
- "투자 전략을 수립해주세요"
- "이 문서를 요약해주세요"
- "비즈니스 아이디어를 검토해주세요"
- "학습 계획을 세워주세요"
```

### **4단계: 파일 업로드**

- **드래그 앤 드롭**으로 파일 업로드
- **AI 분석** 결과 확인
- **다양한 파일 형식** 지원

### **5단계: 실시간 모니터링**

- **시스템 성능** 지표 확인
- **AI 분석 통계** 모니터링
- **실시간 데이터** 업데이트 확인

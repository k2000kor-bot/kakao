🚀 빠른 시작 가이드

서버 시작

터미널에서 ./start_dev_tools.sh 명령어를 실행하여 모든 개발 도구를 한 번에 시작합니다.

채팅 인터페이스 사용

http://localhost:3000 에서 CORBU.AI와 대화하며 코딩 도움을 받을 수 있습니다.

코드 편집기 사용

http://localhost:8080/web_code_editor.html 에서 웹 기반 코드 편집기를 사용할 수 있습니다.

고급 기능 활용

코드 분석, 자동 포맷팅, 파일 분할 등 고급 기능을 활용하여 효율적으로 개발하세요.

## 🎯 **단계별 데모 (10분)**

### **1분: 시스템 접속 및 확인**

```
브라우저에서 접속:
🌐 http://localhost:3000
```

**확인 사항:**

- ✅ 환영 메시지 표시
- ✅ 헤더의 모든 버튼 정상 작동
- ✅ 입력창 정상 작동
- ✅ 설정 옵션들 정상 작동

### **2분: 기본 기능 테스트**

#### **1단계: 간단한 질문**

```
입력: "React란 무엇인가요?"
```

#### **2단계: 품질 설정 변경**

헤더에서 다음 순서로 변경:

1. **기본 품질** → 질문 전송
2. **고급 품질** → 동일 질문 전송
3. **궁극 품질** → 동일 질문 전송

**확인 포인트:**

- 같은 질문이라도 품질 설정에 따라 응답이 달라짐
- 품질이 높을수록 더 상세하고 정확한 응답

### **2분: 입력창 고급 기능**

#### **1단계: 자동 크기 조절**

```
입력: "이것은 매우 긴 질문입니다. 34자를 초과하는 텍스트를 입력하면 
입력창이 자동으로 높이가 늘어나는 것을 확인할 수 있습니다."
```

#### **2단계: 키보드 단축키**

- **Enter**: 메시지 전송
- **Shift+Enter**: 줄바꿈
- **Ctrl+Enter**: 메시지 전송 (대안)

#### **3단계: 34자 제한 확인**

- 입력창 우하단의 문자 수 표시 확인
- 34자 초과 시 자동 줄바꿈 확인

### **2분: 실시간 품질 모니터링**

#### **1단계: 모니터링 시작**

1. 헤더의 **📈** 버튼 클릭
2. **모니터링 시작** 버튼 클릭

#### **2단계: 복잡한 질문으로 테스트**

```
입력: "React와 Vue.js를 비교하여 각각의 장단점과 
사용 사례를 상세히 분석해주세요."
```

#### **3단계: 실시간 품질 추이 확인**

- 📊 **시계열 차트**: 품질 점수 변화
- 📈 **바 차트**: 차원별 품질 분석
- 🍩 **도넛 차트**: 품질 분포

### **2분: 고급 기능 체험**

#### **1단계: 응답 길이 조절**

```
입력: "프로젝트 관리 방법을 알려주세요."
```

헤더에서 길이 설정 변경:

1. **짧게** → 질문 전송
2. **보통** → 동일 질문 전송
3. **길게** → 동일 질문 전송

#### **2단계: 품질 가이드 확인**

1. 헤더의 **📖** 버튼 클릭
2. **5개 탭** 빠르게 탐색:
   - 📋 **개요**: 시스템 전체 개요
   - 📊 **품질 차원**: 8차원 품질 평가 설명
   - 💡 **최적화 팁**: 품질 향상 방법
   - 🎯 **예시**: 실제 사용 시나리오
   - 🚀 **고급 기능**: 고급 기능 활용법

### **1분: 시스템 통합 테스트**

#### **1단계: 테스트 페이지 접속**

```
http://localhost:3000/test
```

#### **2단계: 빠른 테스트 실행**

1. **전체 시스템 테스트 실행** 버튼 클릭
2. **8개 테스트 항목** 진행 상황 확인
3. **테스트 결과** 확인

### **Q3: "성능은 어떤가요?"**

**A3**: "평균 응답 시간 1.8초, 시스템 안정성 99.8%, 품질 점수 92%를 달성했습니다. 이는 기존 시스템 대비 22% 성능 향상, 7-12% 품질 향상을 의미합니다."

### **Q4: "확장성은 어떻게 되나요?"**

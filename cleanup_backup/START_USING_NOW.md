# 🚀 **지금 바로 CORBU AI 사용하기**

## 📋 **빠른 시작 (5분)**

### **1단계: 시스템 접속**
```
브라우저에서 다음 주소로 접속하세요:
🌐 http://localhost:3000
```

### **2단계: 첫 번째 질문**
```
입력창에 다음 중 하나를 입력해보세요:

기본 질문:
- "React란 무엇인가요?"
- "프로젝트 관리 방법을 알려주세요."
- "AI 기술의 현재 동향은?"

복잡한 질문:
- "React의 성능 최적화 방법을 상세히 분석해주세요."
- "프로젝트 리스크 관리 전략을 제시해주세요."
- "AI 기술의 미래 전망과 윤리적 고려사항을 논의해주세요."
```

### **3단계: 설정 실험**
헤더에서 다음 설정들을 변경해보세요:

**품질 설정:**
- **기본 품질** → **고급 품질** → **궁극 품질**

**길이 설정:**
- **짧게** → **보통** → **길게**

**스타일 설정:**
- **간결** → **균형** → **상세**

**톤 설정:**
- **전문적** → **친근** → **중립**

---

## 🎯 **즉시 체험할 수 있는 기능들**

### **1. 입력창 고급 기능**
- **자동 크기 조절**: 긴 텍스트 입력 시 자동으로 높이 증가
- **34자 제한**: 입력창 우하단에 문자 수 표시
- **키보드 단축키**: 
  - Enter: 전송
  - Shift+Enter: 줄바꿈
  - Ctrl+Enter: 전송

### **2. 헤더 기능**
- **📋 사이드 메뉴**: 프로젝트, 세션, 파일 관리
- **📊 품질 대시보드**: 현재 응답의 품질 분석
- **📈 실시간 모니터링**: 품질 추이 실시간 추적
- **📖 품질 가이드**: 최적화 방법 및 팁

### **3. 실시간 품질 모니터링**
1. 헤더의 **📈** 버튼 클릭
2. **모니터링 시작** 버튼 클릭
3. 질문을 입력하고 응답 생성
4. 실시간 품질 추이 확인

### **4. 시스템 통합 테스트**
1. `http://localhost:3000/test` 접속
2. **전체 시스템 테스트 실행** 버튼 클릭
3. 8개 테스트 항목 진행 상황 확인

- ✅ **코드**: 인라인 코드, 코드 블록
- ✅ **링크**: 클릭 가능한 링크
- ✅ **인용**: 인용 블록 스타일링

### **메시지 디자인**
- ✅ **사용자 메시지**: 파란색 그라데이션 배경
- ✅ **AI 메시지**: 흰색 배경, 그림자 효과
- ✅ **아이콘**: 사용자(👤), AI(🤖), 시스템(⚙️)

## 🎯 **효과적인 사용 팁**

### **1. 질문 작성**
- ✅ **구체적**: "React란?" → "React의 핵심 개념과 장점을 설명해주세요."
- ✅ **명확한**: "프로젝트 관리" → "소프트웨어 개발 프로젝트 관리 방법을 알려주세요."
- ✅ **목적 명시**: "성능 최적화 방법을 실제 예제와 함께 설명해주세요."

### **2. 설정 최적화**
- 🚀 **빠른 답변**: 기본 품질 + 짧게
- 📚 **학습 목적**: 고급 품질 + 길게
- 💼 **업무용**: 궁극 품질 + 상세
- 🎨 **창작**: 궁극 품질 + 창의적 톤

### **3. 고급 기능 활용**
- 📈 **품질 모니터링**: 복잡한 질문 시 실시간 품질 추적
- 📖 **품질 가이드**: 특정 분야 질문 시 최적화 팁 참조
- 🔧 **시스템 테스트**: 정기적인 시스템 상태 확인

## 🚨 **문제 해결**

### **일반적인 문제**
- **응답이 느린 경우**: 품질 설정을 "기본 품질"로 변경
- **응답이 너무 긴 경우**: 길이 설정을 "짧게"로 변경
- **품질이 낮은 경우**: 품질 설정을 "궁극 품질"로 변경

### **기술적 문제**
- **페이지 로딩 안됨**: `http://localhost:3000` 접속 확인
- **백엔드 오류**: 헤더의 백엔드 상태 확인
- **기능 오류**: `http://localhost:3000/test`에서 시스템 테스트 실행

## 📋 배포 준비사항

### 🖥️ 시스템 요구사항
- **운영체제**: macOS, Linux, Windows
- **Python**: 3.8 이상
- **메모리**: 최소 2GB RAM
- **디스크**: 최소 1GB 여유 공간
- **네트워크**: 인터넷 연결 (AI 기능용)

### 📦 의존성 패키지
```bash
# 필수 패키지
flask==2.3.3
flask-cors==4.0.0
numpy==1.24.3
requests==2.31.0

# 선택적 패키지 (성능 향상)
psutil==5.9.5  # 시스템 모니터링용
```

### 🔧 설치 가이드
```bash
# 1. 저장소 클론
git clone <repository-url>
cd kakao-frontend

# 2. 가상환경 생성
python3 -m venv venv
source venv/bin/activate  # macOS/Linux
# 또는
venv\Scripts\activate     # Windows

# 3. 의존성 설치
pip install -r requirements.txt

# 4. 서버 실행
python app.py
```

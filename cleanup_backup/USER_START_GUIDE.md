## 🔍 문제 해결

### ❓ **자주 묻는 질문**

**Q: 서버가 시작되지 않아요**
A: 포트 3000이 사용 중일 수 있습니다. 다른 포트로 변경하거나 기존 프로세스를 종료하세요.

**Q: 채팅 응답이 느려요**
A: 네트워크 상태를 확인하고 서버 로그를 확인해보세요.

**Q: 파일 업로드가 안 돼요**
A: 지원되는 파일 형식인지 확인하고 파일 크기를 확인해보세요.

### 🛠️ **기술적 문제 해결**

1. **포트 충돌**: `lsof -ti:3000 | xargs kill -9`
2. **의존성 문제**: `pip install -r requirements.txt`
3. **권한 문제**: 가상환경 활성화 확인

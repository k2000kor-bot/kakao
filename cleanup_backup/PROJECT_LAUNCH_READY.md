## 🚀 런치 명령어

### 1. 개발 환경 런치
```bash
# 개발 서버 시작
npm start

# 백엔드 서버 시작
python3 backend/advanced_api_server.py

# 시스템 상태 확인
curl http://localhost:8000/health
curl http://localhost:3000
```

### 2. 프로덕션 환경 런치
```bash
# Docker 환경 설정
cp env.example .env
# .env 파일을 편집하여 실제 값으로 설정

# 배포 실행
./deploy.sh production

# 상태 확인
docker-compose ps
curl http://localhost:8000/health
curl http://localhost:3000
```

### 3. 모니터링 설정
```bash
# 로그 모니터링
docker-compose logs -f

# 성능 모니터링
curl http://localhost:9090

# 시스템 상태 확인
docker stats
```

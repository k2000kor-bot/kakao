## 🎯 **핵심 기능 체험 순서**

### **1. 기본 기능 테스트 (2분)**

```
질문: "React란 무엇인가요?"
```

**테스트 방법:**

1. **기본 품질**로 질문 전송
2. **고급 품질**로 동일 질문 전송
3. **궁극 품질**로 동일 질문 전송
4. 응답 품질 차이 확인

### **2. 입력창 고급 기능 (2분)**

```
긴 질문 입력:
"이것은 매우 긴 질문입니다. 34자를 초과하는 텍스트를 입력하면 
입력창이 자동으로 높이가 늘어나는 것을 확인할 수 있습니다."
```

**확인 사항:**

- 입력창 자동 크기 조절
- 34자 가로 제한 및 자동 줄바꿈
- 키보드 단축키 (Enter, Shift+Enter, Ctrl+Enter)
- 문자 수 카운터

### **3. 실시간 품질 모니터링 (2분)**

```
복잡한 질문:
"React와 Vue.js를 비교하여 각각의 장단점과 
사용 사례를 상세히 분석해주세요."
```

**모니터링 시작:**

1. 헤더의 **📈** 버튼 클릭
2. **모니터링 시작** 버튼 클릭
3. 실시간 품질 추이 확인

### **4. 고급 기능 체험 (2분)**

```
질문: "프로젝트 관리 방법을 알려주세요."
```

**길이 설정 변경:**

1. **짧게** → 질문 전송
2. **보통** → 동일 질문 전송
3. **길게** → 동일 질문 전송

### **5. 품질 가이드 확인 (1분)**

1. 헤더의 **📖** 버튼 클릭
2. 5개 탭 탐색:
   - 📋 **개요**
   - 📊 **품질 차원**
   - 💡 **최적화 팁**
   - 🎯 **예시**
   - 🚀 **고급 기능**

### **6. 시스템 통합 테스트 (1분)**

```
접속: http://localhost:3000/test
```

1. **전체 시스템 테스트 실행** 버튼 클릭
2. 8개 테스트 항목 진행 상황 확인
3. 테스트 결과 확인

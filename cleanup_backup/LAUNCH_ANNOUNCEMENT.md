## 🌟 CORBU.AI 소개

CORBU.AI는 ChatGPT 스타일의 인터페이스와 강력한 프로젝트 관리 기능을 결합한 차세대 AI 통합 플랫폼입니다. 6단계 AI 처리 파이프라인을 통해 AGI 수준의 지능을 제공하며, 실시간 협업과 고급 콘텐츠 생성 기능을 지원합니다.

### 🎯 핵심 가치

- **🤖 고급 AI**: AGI 수준의 지능과 창의성
- **💼 프로젝트 관리**: 직관적이고 효율적인 워크플로우
- **👥 실시간 협업**: 팀워크를 극대화하는 협업 도구
- **📝 콘텐츠 생성**: 다양한 포맷과 톤의 콘텐츠 자동 생성
- **🔍 고급 분석**: 데이터 기반의 인사이트 제공

## 🚀 주요 기능

### 1. 🤖 AI 통합 시스템


## 🎮 사용 방법

### 기본 사용법

1. **시스템 접속**: <http://localhost:3000>
2. **AI 대화**: 자연어로 질문하고 응답 받기
3. **프로젝트 생성**: 사이드바에서 새 프로젝트 생성
4. **파일 첨부**: 프로젝트에 파일 업로드 및 AI 분석
5. **콘텐츠 생성**: 다양한 포맷으로 콘텐츠 생성

### 고급 기능

```
Ctrl+K: 새 채팅
Ctrl+Enter: 메시지 전송
Ctrl+/: 사이드바 토글
Ctrl+A: 분석 대시보드
Ctrl+L: AI 학습 모드
Esc: 모달 닫기
```

## 🌐 **시스템 아키텍처**

### **백엔드 (Python/FastAPI)**

```
backend/
├── main_server.py              # 메인 서버
├── api/
│   ├── performance_api.py      # 성능 최적화 API
│   ├── ai_engine_api.py        # AI 엔진 API
│   ├── security_api.py         # 보안 모니터링 API
│   ├── user_experience_api.py  # 사용자 경험 API
│   └── websocket_api.py        # WebSocket API
└── venv/                       # 가상환경
```

### **프론트엔드 (React/TypeScript)**

```
src/
├── components/
│   ├── IntegratedDashboard.tsx     # 통합 대시보드
│   ├── PerformanceOptimizer.tsx    # 성능 최적화
│   ├── AdvancedAIEngine.tsx         # AI 엔진 관리
│   ├── AdvancedSecurityMonitor.tsx  # 보안 모니터링
│   ├── EnhancedUserExperience.tsx  # 사용자 경험
│   └── NotificationCenter.tsx      # 알림 센터
├── services/
│   ├── apiService.ts               # API 서비스
│   ├── websocketService.ts         # WebSocket 서비스
│   └── notificationService.ts      # 알림 서비스
└── App.tsx                         # 메인 앱
```

## 🔧 **시스템 관리**

### **서버 시작**

```bash
# 통합 시스템 시작
./start_ultimate_system.sh

# 또는 개별 시작
cd backend && source venv/bin/activate && python3 main_server.py &
npm start &
```

### **서버 중지**

```bash
# 통합 시스템 중지
./stop_ultimate_system.sh
```

- **프론트엔드**: <http://localhost:3000>
- **백엔드 API**: <http://localhost:8000>
- **API 문서**: <http://localhost:8000/api/docs>
- **WebSocket**: ws://localhost:8000/ws

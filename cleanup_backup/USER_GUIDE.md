## 🌟 시스템 개요

**CORBU.AI**는 고급 감정 분석과 의도 파악 기능을 갖춘 AI 어시스턴트입니다.

### ✨ 주요 특징

- **실시간 감정 분석**: 사용자의 감정을 96.5% 정확도로 파악
- **의도 파악**: 질문의 의도를 94.2% 정확도로 분석
- **파일 분석**: 텍스트 파일 업로드 및 분석
- **이미지 분석**: 이미지 파일 업로드 및 기본 분석
- **대화 컨텍스트 유지**: 세션별 대화 기록 관리

---

## 🚀 시작하기

### 1. 시스템 접속

- 브라우저에서 **<http://localhost:3000>** 접속
- 백엔드 서버가 **<http://localhost:5001**에서> 실행 중인지 확인

### 2. 첫 사용

1. 환영 메시지 확인
2. 퀵 액션 버튼으로 간단한 질문 시작
3. 텍스트 입력창에 직접 질문 입력

## 🎯 주요 기능

### 💬 대화 기능

- **일반 대화**: 다양한 주제에 대한 질문과 답변
- **코딩 파트너**: 프로그래밍 관련 도움
- **텍스트 분석**: 텍스트 내용 분석 및 해석

### 📊 AI 분석 결과

각 AI 응답에는 다음 분석 정보가 포함됩니다:

- **감정 분석**: happy, sad, angry, excited, neutral, confused, curious, frustrated
- **의도 분석**: question, greeting, request, complaint, compliment, goodbye, help, information
- **신뢰도**: 각 분석의 정확도 표시

### 🔄 메시지 관리

- **복사**: 메시지 우측 상단의 복사 버튼 클릭
- **재생성**: AI 메시지의 재생성 버튼으로 새로운 답변 생성
- **새 대화**: 사이드바의 "새 대화" 버튼으로 대화 초기화

## 🔧 고급 기능

### 📁 파일 업로드

1. 입력창 왼쪽의 📎 버튼 클릭
2. 지원 형식: `.txt`, `.pdf`, `.doc`, `.docx`, `.csv`, `.json`, `.md`
3. 파일 분석 결과 자동 표시

**분석 내용:**

- 파일 정보 (크기, 줄 수, 단어 수)
- 주요 키워드 추출
- 내용 요약
- 분석 제안

### 🖼️ 이미지 업로드

1. 입력창 왼쪽의 🖼️ 버튼 클릭
2. 지원 형식: 모든 이미지 파일
3. 기본 이미지 정보 표시

**현재 기능:**

- 파일 정보 표시
- 향후 OCR, 객체 감지 등 고급 기능 예정

### 🎤 음성 입력

- 입력창 우측의 마이크 버튼 클릭
- 현재는 준비 중 상태 (향후 구현 예정)

## 🛠️ 문제 해결

### 서버 연결 오류

**증상**: "서버에 연결할 수 없습니다" 메시지
**해결방법**:

1. 백엔드 서버 실행 확인: `python app.py`
2. 포트 5001 사용 가능 여부 확인
3. 방화벽 설정 확인

### 파일 업로드 오류

**증상**: 파일 업로드 실패
**해결방법**:

1. 지원되는 파일 형식인지 확인
2. 파일 크기 확인 (권장: 10MB 이하)
3. 네트워크 연결 상태 확인

### 느린 응답

**증상**: AI 응답이 느림
**해결방법**:

1. 네트워크 연결 상태 확인
2. 서버 리소스 사용량 확인
3. 브라우저 캐시 정리

### 메시지 복사 안됨

**증상**: 복사 버튼 작동 안함
**해결방법**:

1. 브라우저 권한 확인
2. HTTPS 환경에서 사용 (권장)
3. 브라우저 업데이트 확인

### 🔄 실행 방법

#### 1. 백엔드 서버 시작

```bash
cd backend
source venv/bin/activate
python comprehensive_message_api.py
```

#### 2. 프론트엔드 서버 시작

```bash
npm start
```

#### 3. 시스템 테스트

```bash
source backend/venv/bin/activate
python3 system_integration_test.py
```

### 📋 사용 방법

#### 1. 프로젝트 관리

- 사이드바에서 "새 프로젝트" 버튼 클릭
- 프로젝트 이름, 설명, 타입 입력
- 생성된 프로젝트 선택

#### 2. 대화 세션 관리

- 선택된 프로젝트에서 "새 세션" 버튼 클릭
- 세션 제목과 초기 메시지 입력
- 세션 선택하여 대화 시작

#### 3. 실시간 대화

- 메시지 입력 후 Enter 키 또는 전송 버튼 클릭
- 파일 업로드: 📄 (대화 파일), 🎥 (미디어 파일)
- 대화 초기화: 🗑️ 버튼

#### 4. 파일 업로드

- 대화 파일 (.txt): 카카오톡 대화 내보내기 파일
- 미디어 파일: 이미지, 문서, 음성, 비디오
- 실시간 업로드 진행상황 표시

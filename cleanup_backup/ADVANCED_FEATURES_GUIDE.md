# 🚀 CORBU.AI 고급 기능 가이드

## 📋 개요

CORBU.AI는 고급 AI 어시스턴트로, 다양한 기능을 제공하는 통합 플랫폼입니다.

## 🌟 주요 기능

### 1. 💬 실시간 채팅

- **기본 채팅**: 일반적인 질문과 답변
- **감정 분석**: 메시지의 감정 상태 분석
- **의도 파악**: 사용자의 의도를 정확히 파악
- **맞춤형 응답**: 개인화된 답변 제공

### 2. 🔧 고급 도구

#### 📝 코드 리뷰

- **지원 언어**: Python, JavaScript, TypeScript, Java, C++
- **분석 항목**:
  - 코드 품질 검사
  - 잠재적 문제점 발견
  - 개선 제안
  - 복잡도 분석
- **사용법**: 퀵 액션 버튼에서 "코드 리뷰" 클릭

#### 📄 텍스트 요약

- **기능**: 긴 텍스트를 간결하게 요약
- **설정**: 최대 길이 조정 가능 (50-1000자)
- **압축률**: 원본 대비 압축 비율 표시
- **사용법**: 퀵 액션 버튼에서 "텍스트 요약" 클릭

#### 📊 파일 분석

- **지원 형식**: .txt, .md, .json, .py, .js, .ts, .html, .css
- **분석 내용**:
  - 파일 정보 (크기, 줄 수, 단어 수)
  - 주요 키워드 추출
  - 코드 구조 분석 (함수, 클래스, 임포트)
  - 복잡도 점수
- **사용법**: 파일 첨부 버튼 클릭

### 3. ⌨️ 키보드 단축키

- **Ctrl/Cmd + K**: 새 채팅 시작
- **Ctrl/Cmd + /**: 도움말 표시
- **Escape**: 입력 필드 포커스 해제
- **Enter**: 메시지 전송
- **Shift + Enter**: 줄 바꿈

### 4. 🎯 퀵 액션 버튼

- **인사**: 기본 인사말
- **웹 개발**: 웹 개발 관련 질문
- **머신러닝**: 머신러닝 기초 설명
- **데이터 분석**: 데이터 분석 도구 추천
- **코딩 도움**: 프로그래밍 지원
- **창작 도움**: 창작 활동 지원
- **마케팅 콘텐츠**: 마케팅 자료 생성
- **도움말**: 사용법 안내
- **코드 리뷰**: 코드 품질 검사
- **텍스트 요약**: 텍스트 압축
- **시스템 상태**: 성능 메트릭 조회

### 5. 🔄 메시지 관리

- **복사**: 메시지 내용 클립보드 복사
- **재생성**: AI 응답 다시 생성
- **시간 표시**: 각 메시지의 전송 시간
- **분석 결과**: 감정 및 의도 분석 표시

### 6. 📱 반응형 디자인

- **데스크톱**: 전체 기능 사용 가능
- **태블릿**: 최적화된 레이아웃
- **모바일**: 터치 친화적 인터페이스

## 🔧 기술적 특징

### 백엔드 (Flask)

- **포트**: 5001
- **API 엔드포인트**:
  - `/api/chat`: 채팅 처리
  - `/api/analyze-file`: 파일 분석
  - `/api/analyze-image`: 이미지 분석
  - `/api/code-review`: 코드 리뷰
  - `/api/text-summarize`: 텍스트 요약
  - `/api/performance-metrics`: 성능 메트릭
  - `/api/health`: 헬스 체크

### 프론트엔드 (HTML/CSS/JavaScript)

- **포트**: 3000 (React 앱)
- **메인 화면**: 5001 (HTML 직접 서빙)
- **반응형**: CSS Grid/Flexbox
- **애니메이션**: CSS Transitions
- **모달**: 동적 UI 컴포넌트

## 🚀 시작하기

### 1. 서버 실행

```bash
# 백엔드 서버
cd /Users/aD/kakao-frontend
source venv/bin/activate
python app.py

# 프론트엔드 서버 (선택사항)
npm start
```

### 2. 접속

- **메인 화면**: <http://localhost:5001/>
- **React 앱**: <http://localhost:3000/>

### 3. 사용 시작

1. 브라우저에서 <http://localhost:5001/> 접속
2. 퀵 액션 버튼으로 빠른 시작
3. 키보드 단축키 활용
4. 고급 기능 모달 사용

## 💡 사용 팁

### 효율적인 사용법

1. **퀵 액션 활용**: 자주 사용하는 질문을 빠르게 시작
2. **키보드 단축키**: 마우스 없이 빠른 조작
3. **파일 업로드**: 코드나 문서를 직접 분석
4. **모달 기능**: 고급 도구를 체계적으로 사용

### 최적화 팁

1. **메시지 복사**: 중요한 정보를 쉽게 저장
2. **재생성**: 만족스럽지 않은 응답을 다시 생성
3. **새 채팅**: 주제별로 대화 분리
4. **모드 전환**: 용도에 맞는 AI 모드 선택

## 🔍 문제 해결

### 일반적인 문제

1. **서버 연결 오류**: 포트 5001이 사용 중인지 확인
2. **파일 업로드 실패**: 지원되는 형식인지 확인
3. **모달이 열리지 않음**: JavaScript 활성화 확인
4. **키보드 단축키 작동 안함**: 브라우저 포커스 확인

### 성능 최적화

1. **메시지 제한**: 자동으로 최근 50개 메시지만 유지
2. **파일 크기**: 큰 파일은 분석 시간이 오래 걸림
3. **네트워크**: 안정적인 인터넷 연결 필요

# 명세 기반 문서·긴 글 편집

긴 원문을 **요구·참고·금지사항**에 맞게 바꿀 때, 추측으로 내용을 만들지 않고 **추적 가능한 변경**만 하도록 한다.

## 1. 입력 분류 (먼저 수행)

다음이 비어 있으면 **한 번에 질문**해 보충한다 (추측으로 채우지 않음).

| 구분 | 내용 |
|------|------|
| **원문** | 붙여넣기, 파일 경로, `@` 문서, 또는 **`https://` 링크**(아래 §4) |
| **목표** | 예: 요약, 톤 통일, 섹션 재배치, 용어 치환, 법/정책 문구 반영 |
| **필수 반영** | 반드시 들어가야 할 문장·조항·수치·이름 (출처 명시) |
| **참고** | 따올 근거, 스타일 샘플, 비교 대상 문서 |
| **비목표** | 하지 말 것 (삭제 금지 구간, 바꾸면 안 되는 인용 등) |
| **출력 형식** | Markdown/한글/영문, 표·번호 체계, 최대 길이 |

## 2. 작업 순서

1. **요구 추출**: 사용자 문장을 체크리스트 항목으로 바꾼다 (추상 요청은 구체 조건으로 분해).
2. **원문 맵**: 큰 덩어리(섹션/단락) 단위로 경계를 잡고, 변경 대상 구간을 번호나 인용으로 지정한다.
3. **변경 계획**: 각 항목마다 「원문 위치 → 무엇을 어떻게」 한 줄씩 적는다 (삭제·이동·병합 포함).
4. **적용**: 한 번에 전부 섞지 말고, **계획 순서**대로 반영. 새 사실·수치는 **원문·참고에 없으면 넣지 않거나** `[확인 필요]`로 표시.
5. **대조 검증**: 체크리스트를 다시 읽으며 빠진 항목·금지 위반·톤 불일치를 수정.

## 3. 충돌·우선순위

요구·참고·원문이 어긋나면 다음 순으로 판단한다: **사용자가 이번 턴에 명시한 필수 조건** → **원문에 이미 있는 사실** → **참고 문서의 구조·톤** → 일반적인 문장 다듬기. 수치·이름·인용은 원문/참고에 근거가 없으면 만들지 않는다.

## 4. URL·링크가 원문 또는 참고일 때

- 사용자가 준 **`http(s)` URL**이면, 환경에서 허용되는 경우 **페이지를 가져와(fetch)** 본문 텍스트를 확보한 뒤, 그것을 **원문**으로 §2를 적용한다. 참고용 링크만 주어진 경우에도 동일하게 가져와 **참고**로 쓴다.
- **실패 시**(로그인 필요, 봇 차단, JS 전용 렌더, 403/빈 본문): 사용자에게 알리고 **대안**을 요청한다 — 해당 구간 **직접 붙여넣기**, 내보낸 **파일/PDF**, 공개 미러·아카이브 링크 등.
- 가져온 HTML은 **본문 위주**로 정리한다(내비·푸터·광고 제거). 인용·수치는 **페이지에 적힌 그대로**만 쓰고, 불명확하면 `[확인 필요]` 또는 원문 인용 블록.
- **출처**: 결과물 하단 또는 해당 절에 **URL**, 가능하면 **페이지 제목·인용 시점**을 남긴다.
- **안전**: 사용자가 이번 턴에 명시한 URL만 요청한다. 의심스러운 리다이렉트·비표준 스킴은 열지 않는다.

## 5. Cursor에서 맥락을 최대로 쓰는 방법

- 원문은 **파일로 두고 `@경로`**로 넣으면 긴 글도 안정적으로 붙는다. 링크만 있을 때는 §4로 본문을 확보한 뒤, 필요하면 **작업용 `.md`로 저장**하고 `@`로 고정한다.
- 요구는 **번호 목록**으로 주면 항목 누락 검증이 쉽다.
- 한 번에 못 돌리면 **섹션 단위**(예: "2장만")로 나눠 반복한다.
- 이 스킬을 쓰려면 대화에서 **`@spec-driven-document-edit`**(또는 해당 `SKILL.md` 파일)을 함께 지정한다.

## 6. 품질 규칙

- **근거 우선**: 참고/원문과 충돌하면 사용자에게 질문하거나 양안을 짧게 병기.
- **침묵 삭제 금지**: 큰 단락을 지우면 이유를 한 줄이라도 남기거나 사용자 확인.
- **용어 일관**: 한 문서 안에서 동일 개념은 동일 표기 (처음 나올 때만 약어 정의 가능).
- **차분**: 요구가 모호하면 **가정**을 명시한 뒤 그 가정 하에서만 문장을 쓴다.

## 7. 사용자가 붙여 넣을 수 있는 요청 템플릿

아래를 채워 보내면 에이전트가 위 절차를 따르기 쉽다.

```markdown
## 원문
(긴 글 붙여넣기, 또는 `파일: 경로`, 또는 `URL: https://...`)

## 이번에 꼭 해야 할 것
- 

## 참고 (그대로 반영하거나 톤만 맞출 것)
- 

## 하지 말 것
- 

## 결과물 형식
- 예: Markdown, 표 유지, 섹션명 유지, 최대 N자
```

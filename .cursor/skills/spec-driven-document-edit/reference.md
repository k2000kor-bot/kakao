# 보조 참고 (필요할 때만 읽기)

## 짧은 예시: 요구만 주어진 경우

**나쁜 진행**: 원문을 대충 요약하고 사용자가 말한 세부는 빠뜨림.

**좋은 진행**: 사용자 요구를 항목 리스트로 옮긴 뒤, 각 항목에 대응하는 문단/문장을 결과에 표시하거나 번호로 연결.

## 긴 스레드에서 문맥이 끊길 때

- 이전 턴의 「필수 반영」을 현재 턴 상단에 한 줄로 재진술.
- 파일로 고정: 원문을 레포에 임시 `.md`로 저장하고 경로만 주면 반복 편집에 유리.
- **아주 긴 원문**: 섹션 헤더 기준으로 잘라 「이번 턴 = §3~§5만」처럼 범위를 고정하고, 결과를 같은 파일에 이어 붙이거나 패치로 합친다.

## 에이전트가 잘못하기 쉬운 지점

- 법·의료·수치: 원문에 없으면 생성하지 않음.
- "비슷하게": 참고 문서의 **구조**만 복제하고 **사실**은 원문에서만 취함.

## 링크만 줄 때

- Fetch가 **스니펫·메타만** 주면 본문이 비어 있을 수 있음 → 사용자에게 본문 붙여넣기 요청.
- **PDF/Doc 링크**는 브라우저 fetch로는 못 읽는 경우가 많음 → 다운로드 후 파일로 주거나 텍스트 추출 도구 사용을 안내.

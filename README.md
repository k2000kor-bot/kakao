# CORBU AI - 고도화된 지능형 AI 분석 플랫폼 🚀

## 프로젝트 개요

CORBU AI는 ChatGPT 스타일의 대화형 인터페이스를 통해 모든 AI 기능에 접근할 수 있는 **고도화된 통합 AI 플랫폼**입니다. 사용자는 자연스러운 대화를 통해 AI 분석, 최적화, 심리학, 학습, 비즈니스 워크플로우 등 다양한 AI 기능을 활용할 수 있으며, **복합 질문 분석 및 종합 답변 생성 시스템**을 통해 체계적이고 포괄적인 AI 서비스를 제공합니다.

## 🎯 핵심 혁신 기능

### 🤖 **복합 질문 분석 및 종합 답변 시스템**

- **지능형 요구사항 파악**: 사용자 질문에서 분석, 최적화, 예측, 비교, 권장사항 등 다양한 요구사항을 자동으로 인식
- **맥락 기반 응답 생성**: 질문의 맥락과 요구사항을 종합하여 체계적이고 포괄적인 답변 제공
- **후속 질문 제안**: AI가 사용자의 다음 단계를 안내하는 스마트한 질문 제안 시스템

### 📊 **실시간 데이터 시각화 및 모니터링**

- **실시간 시스템 모니터링**: CPU, 메모리, 네트워크, 사용자 활동 등 실시간 성능 지표 시각화
- **고급 차트 및 그래프**: 성능 트렌드, 사용자 만족도, AI 모델 성능 비교 등 다양한 시각화 제공
- **동적 데이터 업데이트**: 3초마다 자동으로 업데이트되는 실시간 데이터

### 🏆 **다중 AI 모델 선택 및 성능 최적화**

- **5가지 AI 모델 지원**: GPT-4, Claude 3, Gemini Pro, GPT-3.5, 커스텀 모델
- **모델별 특성 반영**: 각 AI 모델의 고유한 특성을 반영한 맞춤형 응답 생성
- **성능 비교 시각화**: 원형 차트를 통한 직관적인 AI 모델 성능 비교

### 👥 **실시간 협업 및 팀워크 시스템**

- **실시간 협업 채팅**: 팀원들과의 실시간 소통 및 아이디어 공유
- **협업자 상태 모니터링**: 온라인/오프라인 상태 및 역할별 정보 표시
- **프로젝트 기반 협업**: 프로젝트별로 구분된 협업 공간 제공

## 특별 기능 🌟

- **전문적인 부동산 분석**: 투자 규모, 분양가, 예상 수익률, ROI 분석
- **프로젝트 일정 및 리스크 분석**: 상세 일정, 리스크 요소, 전략적 권장사항
- **미래 전망 예측**: 2027년 완공까지의 단계별 진행 계획

### 대화형 질문 추천 시스템

- **컨텍스트 기반 질문 생성**: 사용자 입력에 따른 스마트한 후속 질문 제안
- **카테고리별 질문 템플릿**: AI 분석, AI 심리학, AI 학습 등 분야별 질문 가이드
- **단계별 질문 진행**: 분석 → 최적화 → 구현 → 평가의 논리적 질문 흐름

## 기술 스택 🛠️

- **Frontend**: React 18 + TypeScript
- **UI Library**: Material-UI (MUI) v5
- **State Management**: React Hooks (useState, useEffect, useRef)
- **Build Tool**: Create React App
- **Language**: TypeScript
- **Styling**: MUI Theme System + CSS-in-JS
- **Icons**: Material-UI Icons + Custom Emojis
- **Responsive Design**: Grid System + Breakpoint-based Layout

## 설치 및 실행 🚀

### 필수 요구사항

- Node.js 16.0.0 이상
- npm 8.0.0 이상
- 최신 웹 브라우저 (Chrome, Firefox, Safari, Edge)

### 설치

```bash
# 저장소 클론
git clone [repository-url]
cd kakao-frontend

# 의존성 설치
npm install
```

### 개발 서버 실행

```bash
npm start
```

개발 서버가 시작되면 [http://localhost:3000](http://localhost:3000)에서 애플리케이션에 접근할 수 있습니다.

### 빌드

```bash
npm run build
```

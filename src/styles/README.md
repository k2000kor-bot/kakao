# Styles

## 파일

| 파일 | 용도 |
|------|------|
| **theme.css** | CSS 변수(색·폰트·간격), 라이트/다크 테마 |
| **brainwave-global.css** | bw-detail-*, bw-flex-*, bw-page-input-dock 등 공통 클래스 |
| **themeColors.ts** | CHART_COLORS, getStatusColor, getQualityScoreColor 등 |
| **responsive.css** | 반응형 breakpoint |
